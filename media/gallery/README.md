# Gallery demo videos

One short video per gallery example: the example opens, runs, and is
filmed working. 1920x1080, split intro card (logo + title + board on the
left, the whole circuit on the right), lower third, outro and soundtrack.

Produced by `scripts/gallery-record.mjs` + `scripts/gallery-bbox.mjs` +
`scripts/gallery-render.mjs` (see `skills/velxio-promo-video/SKILL.md`).
Click a file to play it on GitHub.
