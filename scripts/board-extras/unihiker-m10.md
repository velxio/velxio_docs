## About this board

DFRobot's UNIHIKER M10 is an education SBC — a Linux board with a **built-in
touchscreen** — and in Velxio it runs on the same infrastructure as the
Raspberry Pi family rather than as a microcontroller: a real shell, real
Python, and GPIO bridged to whatever you wire on the canvas.

Because of that it is documented with the
[Raspberry Pi (Linux) family](/docs/boards/raspberry-pi/), not with the
partner boards it sits beside in the picker.

## Start here

Place the board and press **Start**, then wait for Linux — the
[Raspberry Pi family page](/docs/boards/raspberry-pi/) covers the boot, the
shell and the file upload panel.

The UNIHIKER needs a **paid plan**, the only board in the partner catalog that
does — see [plans](/docs/getting-started/plans/).
