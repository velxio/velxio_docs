## About this board

The XIAO ESP32S3 with the Sense expansion: an S3 the size of a thumbnail that
also carries a **camera, a PDM microphone and a microSD slot**. All three are
emulated, so the sensor projects produce real data rather than placeholders.

If you want the plain S3 without the sensor board, that is
[XIAO ESP32-S3](/docs/boards/reference/xiao-esp32-s3/).

## Start here

- [Hello](https://velxio.dev/example/xiao-esp32s3-sense-hello) — the board
  running, nothing else.
- [Camera photos to microSD](https://velxio.dev/example/xiao-esp32s3-sense-camera)

- [PDM microphone level](https://velxio.dev/example/xiao-esp32s3-sense-mic) and
  [on-board microSD](https://velxio.dev/example/xiao-esp32s3-sense-sd) take one
