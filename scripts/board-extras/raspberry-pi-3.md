## About this board

A Cortex-A53 Pi running **real Linux**, not a microcontroller emulation: you
get a shell, `python3`, `pip` and a genuine userland, with the GPIO header
wired to the canvas so `gpiozero` drives the components you placed.

This page's art is shared with the **Zero, 1 and 2** — they are the same
board outline in the picker, and the same Linux workflow.

## Start here

Place the board, press **Start**, and wait for the shell — Linux takes 30 to
60 seconds to boot, with an overlay tracking it. The
[Raspberry Pi family page](/docs/boards/raspberry-pi/) walks the whole flow,
including the file panel that uploads your scripts into the running system.

Pi boards need a **paid plan** — see [plans](/docs/getting-started/plans/).
