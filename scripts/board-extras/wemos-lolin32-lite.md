## About this board

A compact ESP32 in the Lolin footprint, with a LiPo charger on board — the
same dual-core Xtensa chip and the same simulator support as the
[DevKit V1](/docs/boards/reference/esp32/), in 26 pins.

Pick it when the physical board you are prototyping for is this one; the code
side is identical to any other classic ESP32, so examples written for the
DevKit run unchanged as long as the pins exist here.

## Start here

No separate starter: open
[New ESP32 project](https://velxio.dev/example/esp32-blink-led) and swap the
board, or place it from **Add Component**.
