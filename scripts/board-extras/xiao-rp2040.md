## About this board

The RP2040 in the XIAO footprint, with an **on-board RGB LED** — which is why
this board's examples are about colour rather than about a single blinking
pin.

The chip is the same one in the [Pico](/docs/boards/reference/raspberry-pi-pico/),
so RP2040 code ports across; what changes is how many pins come out, and the
map below is the authority on that.

## Start here

- [On-board RGB LED](https://velxio.dev/example/xiao-rp2040-rgb) — the board's
  own hello.
- [Button cycles the RGB](https://velxio.dev/example/xiao-rp2040-button) adds an
  input, and [traffic light](https://velxio.dev/example/xiao-rp2040-traffic-light)
  turns it into a small state machine.
