## About this board

The reference ESP32-C3 devkit — single-core **RISC-V** with WiFi and BLE,
Espressif's small and cheap tier. The instruction set is the only real
difference from a sketch's point of view: the Arduino API, the peripherals and
the language trio are the same as on the classic ESP32.
