## About this board

Olimex's STM32F405RG header board: Cortex-M4 with FPU, in an industrial-style
layout rather than the hobby pill footprint.

Same STM32duino core and the same Arduino API surface as the rest of the
family — the board is here so that projects designed around Olimex hardware
can be prototyped against the pinout they will actually ship on.
