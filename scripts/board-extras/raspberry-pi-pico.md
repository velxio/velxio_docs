## About this board

The standard RP2040 Pico: dual-core Cortex-M0+, emulated in the browser, with
**PIO** — the programmable I/O blocks that make the RP2040 worth its price and
that the NeoPixel and odd-protocol examples lean on.

MicroPython is this board's native habitat here: the REPL comes up in the
[serial monitor](/docs/programming/serial-monitor/) and you can type at it
while the sketch runs. Arduino C++ works too, through the earlephilhower core.

## Start here

[New Raspberry Pi Pico project](https://velxio.dev/example/pico-blink) opens
the editor with this board and a working blink sketch. The gallery has one of
the deepest example sets in the catalog on this board — I2C scanner, SPI
loopback, ADC, servo, ultrasonic, OLED, e-paper clocks, even a raycaster.
