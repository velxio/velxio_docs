The [component picker](/docs/circuit-editor/placing-components/) groups
the catalog into these categories — use its dropdown filter or search to
navigate the same way:

| Category              | What's in it                                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Boards**            | Everything that executes code — see [Boards](/docs/boards/overview/)                                               |
| **Displays**          | OLEDs (SSD1306), character LCDs (1602/2004), TFTs (ILI9341, GC9A01), e-paper, 7-segments, LED matrices             |
| **Sensors**           | Temperature/humidity (DHT22, DS18B20, BMP280), distance (HC-SR04), motion (PIR, MPU6050), light, gas, GPS          |
| **Input**             | Pushbuttons, slide/DIP switches, potentiometers, rotary encoders (KY-040), joysticks, membrane keypads, IR remotes |
| **Output**            | LEDs (single, RGB, bars, rings, NeoPixel strips), buzzers, relay modules                                           |
| **Motors**            | Servos, DC motors, steppers with their drivers (A4988 and friends)                                                 |
| **Communication**     | UART/I2C/SPI helper modules, RTCs (DS1307, DS3231), EEPROMs, microSD                                               |
| **Passive**           | Resistors, capacitors, breadboards, the wiring staples                                                             |
| **Logic Gates**       | Discrete gates, flip-flops and the 74xx family (74HC595, 74HC165…)                                                 |
| **Analog**            | Diodes, transistors, op-amps, voltage regulators                                                                   |
| **Electromechanical** | Relays and their kin                                                                                               |
| **Other**             | The [custom chip](/docs/custom-chips/overview/) and everything uncategorizable                                     |

Branded modules — **DFRobot**, **Seeed Studio / Grove**, **M5Stack** —
appear in their functional category with the brand on the card and a
**PRO badge** where a paid plan is needed.

## Per-part pages

Each part's full reference — pinout, editable attributes, electrical
values, linked examples — is available in the editor via
**right-click → Datasheet** ([part inspector](/docs/circuit-editor/part-inspector/)).
Per-part pages in this section are being generated from the same
registry and published in batches.
