This section is the reference for every part in the component picker: LEDs
and displays, sensors, motors and drivers, logic ICs, analog parts, power,
and branded modules (DFRobot, Seeed Studio, M5Stack, Grove).

Each part page includes:

- A photo and the interactive pinout.
- The attributes you can edit in the properties panel.
- The datasheet summary you also get by right-clicking the part in the
  editor.
- A working example project to open in one click.

> This reference is generated from the same component registry the app
> uses, so pinouts and attributes always match what you see on the canvas.
