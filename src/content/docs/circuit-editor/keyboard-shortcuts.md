## Project

| Shortcut   | Action                          |
| ---------- | ------------------------------- |
| **Ctrl+S** | Save project                    |
| **Ctrl+B** | Compile the active board's code |

## Canvas

| Shortcut                   | Action                                                     |
| -------------------------- | ---------------------------------------------------------- |
| **Delete** / **Backspace** | Remove the selected part or wire                           |
| **Escape**                 | Cancel the wire being drawn                                |
| Right-click a part         | Open its [inspector](/docs/circuit-editor/part-inspector/) |

## Wire colors

With a wire in progress or selected — see
[Wiring](/docs/circuit-editor/wiring/) for the palette:

| Shortcut | Color                                                             |
| -------- | ----------------------------------------------------------------- |
| **0–9**  | Black, Brown, Red, Orange, Gold, Green, Blue, Violet, Gray, White |
| **c**    | Cyan                                                              |
| **l**    | Lime green                                                        |
| **m**    | Magenta                                                           |
| **p**    | Purple                                                            |
| **y**    | Yellow                                                            |

## Code editor

The standard editing shortcuts you expect (select, duplicate, comment
toggling) work inside the code editor.

## AI chat

| Shortcut        | Action           |
| --------------- | ---------------- |
| **Enter**       | Send the message |
| **Shift+Enter** | New line         |
