Vous pouvez ouvrir Velxio et simuler sans compte. L'inscription (e-mail +
vérification) ajoute les éléments qui doivent persister :

- **Saved projects** (Projets enregistrés) — votre travail, disponible depuis n'importe quel appareil.
- **Public project links** (Liens de projets publics) — partagez un circuit avec une seule URL.
- **Plan features** (Fonctionnalités du plan) — un abonnement payant est rattaché à votre compte ; voir
  [plans](/docs/fr/getting-started/plans/).

## Se connecter

Utilisez **Sign in** (Se connecter) sur le site ou le menu **Account** (Compte) dans l'éditeur. Votre
avatar apparaît en bas à gauche de l'éditeur lorsque vous êtes connecté.

## Langue de l'interface

L'interface de Velxio est disponible en plusieurs langues — anglais, espagnol,
portugais, italien, français, chinois, allemand, japonais et russe. Changez
avec le sélecteur de langue (icône globe) dans l'en-tête du site ; l'éditeur
suit.

## Se déconnecter et données du compte

Déconnectez-vous depuis le menu **Account** (Compte). Vos projets enregistrés restent dans votre
compte ; les liens publics continuent de fonctionner tant que le projet reste public.
