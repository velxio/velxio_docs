Vous pouvez utiliser Velxio sans compte, mais vous connecter vous permet de sauvegarder
vos projets, de les synchroniser entre vos appareils et de débloquer des fonctionnalités payantes.

Dans cette section :

- **Account** (Compte) — inscription, connexion, profil et langue de l'interface.
- **Subscription** (Abonnement) — souscrire, gérer ou annuler votre plan, factures.
- **Troubleshooting** (Dépannage) — que vérifier lorsque la simulation ne démarre pas,
  que la compilation est lente ou que le flash web ne détecte pas votre carte.
