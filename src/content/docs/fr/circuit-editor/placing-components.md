Cliquez sur **Add** (Ajouter) dans la barre d'outils (ou sur le bouton **+** du canevas) pour ouvrir
le sélecteur de composants :

![Le sélecteur de composants](../../../../assets/docs/circuit-editor/component-picker.png)

- **Search** (Rechercher) par nom ou fonction : `oled`, `dht`, `resistor`, `servo`…
- **Filter** (Filtrer) par catégorie avec le menu déroulant à droite — cartes,
  écrans, capteurs, moteurs, logique, pièces analogiques et modules de marque.
- Les cartes avec un **PRO badge** nécessitent un plan payant pour _exécuter_ — vous pouvez voir
  tout le catalogue indépendamment. Voir [plans](/docs/fr/getting-started/plans/).

Cliquez sur une carte et la pièce atterrit sur le canevas. Ensuite :

- **Drag** (Glisser) pour la positionner.
- **Click** (Cliquer) pour la sélectionner (un cadre en pointillés indique la sélection).
- **Right-click** (Clic droit) pour ouvrir l'[inspecteur de pièces](/docs/fr/circuit-editor/part-inspector/) —
  propriétés, brochage, fiche technique, rotation et suppression.
- **Delete** (Supprimer) ou **Backspace** (Retour arrière) supprime la pièce sélectionnée.

Chaque pièce sur le canevas est active pendant la simulation : les LED s'allument, les écrans
affichent, les boutons cliquent, les capteurs rapportent les valeurs que vous leur définissez.

Le catalogue complet, avec une page par pièce, se trouve dans la
[référence des pièces](/docs/fr/parts/overview/).
