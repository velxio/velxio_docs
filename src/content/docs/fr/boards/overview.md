Velxio simule des cartes de six familles. Certaines fonctionnent entièrement dans votre
navigateur ; les plus grandes fonctionnent sur les émulateurs cloud de Velxio — vous n'avez rien
à faire de différent, cela fonctionne simplement lorsque vous appuyez sur **Play** (Lecture).

| Famille               | Cartes                                                     | Langages                            |
| --------------------- | ---------------------------------------------------------- | ----------------------------------- |
| Arduino / AVR         | UNO, Nano, Mega, ATtiny85                                  | Arduino C++                         |
| ESP32 classique       | ESP32 DevKit, DevKit-C v4, ESP32-CAM, Lolin32 Lite         | Arduino C++, MicroPython, ESP-IDF   |
| ESP32-S3              | ESP32-S3, XIAO ESP32-S3, Arduino Nano ESP32                | Arduino C++, MicroPython, ESP-IDF   |
| ESP32-C3              | ESP32-C3, XIAO ESP32-C3, C3 SuperMini                      | Arduino C++, MicroPython, ESP-IDF   |
| RP2040 / RP2350       | Raspberry Pi Pico, Pico W, Badger 2350 (Pro)               | Arduino C++, MicroPython            |
| STM32                 | Blue Pill, Black Pill, F4 Discovery, Olimex H405, Netduino | Arduino C++                         |
| Raspberry Pi (Linux)  | Zero, 1, 2, 3, 4, 5                                        | Python sur un terminal Linux complet |

Les familles **STM32** et **Raspberry Pi (Linux)** fonctionnent sur les serveurs
d'émulation de Velxio et nécessitent un plan payant ; elles portent un badge PRO dans le
sélecteur de composants. Toutes les autres cartes, y compris celles de marque comme la
M5Stack Cardputer et la Badger 2350, fonctionnent avec le plan gratuit — voir
[plans](/docs/fr/getting-started/plans/).

Chaque carte a sa propre page dans cette section avec son brochage, ses langages
pris en charge et ses particularités.
