## Enregistrer un projet

Cliquez sur l'**icône d'enregistrement** au-dessus de l'arborescence de fichiers ou appuyez sur **Ctrl+S** :

![La boîte de dialogue d'enregistrement de projet](../../../../assets/docs/getting-started/save-project.png)

Donnez-lui un nom et, facultativement, une description. Le paramètre de **visibilité**
contrôle qui peut le voir :

- **Public** — toute personne disposant du lien peut voir le projet.
- **Privé** — vous uniquement. Les projets privés sont une fonctionnalité payante ; voir
  [plans](/docs/fr/getting-started/plans/).

Les projets enregistrés vivent dans votre compte et s'ouvrent depuis n'importe quel appareil une fois que vous êtes
connecté.

## Démarrer un nouveau projet

L'icône **nouvel espace de travail** au-dessus de l'arborescence de fichiers ouvre le sélecteur de modèles :

![Le sélecteur de modèles de démarrage](../../../../assets/docs/getting-started/starter-templates.png)

Choisissez un **projet vierge** pour démarrer avec un canevas vide, ou choisissez une carte pour
obtenir cette carte pré-placée avec un exemple de clignotement prêt à l'emploi — organisé par
famille (Arduino, ESP32, etc.).

:::caution
Démarrer un nouvel espace de travail **remplace tout dans l'espace actuel** — enregistrez
d'abord si vous souhaitez conserver ce que vous avez.
:::

## Ouvrir un fichier de projet

L'**icône d'ouverture** au-dessus de l'arborescence de fichiers charge un projet depuis le disque :

- **`.vlx`** — le format de projet propre à Velxio (circuit + code + bibliothèques).
- **`.zip` (Wokwi)** — Velxio importe les archives de projets Wokwi, vous pouvez donc
  apporter vos projets Wokwi existants avec vous.

## Partager un projet

Enregistrez le projet comme **Public** et partagez son URL. Toute personne qui ouvre le
lien voit le circuit et le code, et peut l'exécuter elle-même.
