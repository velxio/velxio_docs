Velxio propose une galerie de **plus de 400 projets d'exemple** — chacun s'ouvre dans l'éditeur en un seul clic, prêt à être exécuté. C'est le meilleur point de départ lorsque vous explorez une nouvelle carte ou un nouveau composant.

Retrouvez-la sur [velxio.dev/examples](https://velxio.dev/examples), ou via **Examples** dans la navigation du site.

![La galerie d'exemples](../../../../assets/docs/getting-started/examples-gallery.png)

## Trouver un exemple

- **Search** (Recherche) — essayez une pièce ou un sujet : `esp32 oled`, `blink`, `dht`…
- **Board filter** (Filtre par carte) — uniquement les exemples pour la carte qui vous intéresse.
- **Difficulty** (Difficulté) — Débutant / Intermédiaire / Avancé.
- **Category** (Catégorie) — Circuits, Affichages, Moteurs, et plus encore.

Chaque carte affiche un aperçu du circuit, la carte cible et une brève description de ce que le projet démontre.

## Utiliser un exemple

Cliquez sur une carte et le projet complet s'ouvre dans l'éditeur — circuit câblé, code écrit, bibliothèques déclarées. Appuyez sur **Run** et tout fonctionne. Ensuite, considérez-le comme le vôtre : modifiez le code, ajoutez des pièces et [enregistrez-le](/docs/fr/getting-started/projects/) sur votre compte.

Les exemples sont également liés depuis les pages de référence : chaque [page de pièce](/docs/fr/parts/overview/) et [page de carte](/docs/fr/boards/overview/) pointe vers des exemples qui l'utilisent, et l'[inspecteur de pièces](/docs/fr/circuit-editor/part-inspector/) dans l'éditeur répertorie les projets d'exemple pour la pièce sur laquelle vous avez fait un clic droit.
