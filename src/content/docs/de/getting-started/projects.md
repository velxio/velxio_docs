## Projekt speichern

Klicken Sie auf das **save icon** über dem Dateibaum oder drücken Sie **Ctrl+S**:

![Der Dialog zum Speichern von Projekten](../../../../assets/docs/getting-started/save-project.png)

Geben Sie einen Namen und optional eine Beschreibung ein. Die Einstellung **visibility** (Sichtbarkeit) legt fest, wer das Projekt sehen kann:

- **Public** (Öffentlich) — jeder mit dem Link kann das Projekt ansehen.
- **Private** (Privat) — nur Sie. Private Projekte sind ein Merkmal kostenpflichtiger Tarife; siehe [Tarife](/docs/de/getting-started/plans/).

Gespeicherte Projekte befinden sich in Ihrem Konto und können von jedem Gerät geöffnet werden, sobald Sie angemeldet sind.

## Ein neues Projekt starten

Das **new workspace**-Symbol über dem Dateibaum öffnet die Vorlagenauswahl:

![Die Auswahl der Startvorlagen](../../../../assets/docs/getting-started/starter-templates.png)

Wählen Sie ein **blank project** (leeres Projekt), um mit einer leeren Arbeitsfläche zu beginnen, oder wählen Sie ein Board, um dieses Board mit einem fertigen Blink-Beispiel vorplatziert zu erhalten — sortiert nach Familie (Arduino, ESP32 usw.).

:::caution
Das Starten eines neuen Arbeitsbereichs **ersetzt alles im aktuellen Arbeitsbereich** — speichern Sie zuerst, wenn Sie Ihre Arbeit behalten möchten.
:::

## Eine Projektdatei öffnen

Das **open icon** über dem Dateibaum lädt ein Projekt von der Festplatte:

- **`.vlx`** — Velxios eigenes Projektformat (Schaltkreis + Code + Bibliotheken).
- **`.zip` (Wokwi)** — Velxio importiert Wokwi-Projektarchive, sodass Sie bestehende Wokwi-Projekte mitbringen können.

## Ein Projekt teilen

Speichern Sie das Projekt als **Public** und teilen Sie seine URL. Jeder, der den Link öffnet, sieht den Schaltkreis und den Code und kann ihn selbst ausführen.
