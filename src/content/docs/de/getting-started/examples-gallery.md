Velxio enthält eine Galerie mit **über 400 Beispielprojekten** – jedes davon lässt sich
mit einem einzigen Klick im Editor öffnen und ist sofort ausführbar. Es ist der beste Ausgangspunkt,
wenn du ein neues Board oder eine neue Komponente erkundest.

Du findest sie unter [velxio.dev/examples](https://velxio.dev/examples) oder über
**Examples** (Beispiele) in der Site-Navigation.

![Die Beispielgalerie](../../../../assets/docs/getting-started/examples-gallery.png)

## Ein Beispiel finden

- **Search** (Suchen) – gib ein Bauteil oder ein Thema ein: `esp32 oled`, `blink`, `dht`…
- **Board filter** (Board-Filter) – nur Beispiele für das Board, das dich interessiert.
- **Difficulty** (Schwierigkeitsgrad) – Anfänger / Fortgeschritten / Experte.
- **Category** (Kategorie) – Schaltungen, Displays, Motoren und mehr.

Jede Karte zeigt eine Vorschau der Schaltung, das Ziel-Board und eine kurze
Beschreibung dessen, was das Projekt demonstriert.

## Ein Beispiel verwenden

Klicke auf eine Karte und das vollständige Projekt öffnet sich im Editor – Schaltung verdrahtet,
Code geschrieben, Bibliotheken deklariert. Drücke **Run** (Ausführen) und es funktioniert. Von dort an
behandle es als dein eigenes: Bearbeite den Code, füge Bauteile hinzu und
[speichere es](/docs/de/getting-started/projects/) in deinem Konto.

Beispiele sind auch von den Referenzseiten aus verlinkt: Jede
[Bauteilseite](/docs/de/parts/overview/) und [Board-Seite](/docs/de/boards/overview/)
verweist auf Beispiele, die das jeweilige Element verwenden, und der
[Bauteilinspektor](/docs/de/circuit-editor/part-inspector/) im Editor
listet Beispielprojekte für das Bauteil auf, das du mit Rechtsklick ausgewählt hast.
