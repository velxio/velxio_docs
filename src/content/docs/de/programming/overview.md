Jedes Velxio-Projekt enthält zugehörigen Code. Sie schreiben ihn im integrierten Editor,
drücken **Play**, und Velxio kompiliert und führt ihn auf dem emulierten Board aus.

- **Sprachen** — Arduino C++, MicroPython oder ESP-IDF, je nachdem, welches
  Board Sie ausgewählt haben.
- **Bibliotheken** — Verwenden Sie Arduino-Bibliotheken und MicroPython-Pakete in Ihrem
  Projekt.
- **Serieller Monitor** — Sehen Sie die Ausgabe Ihres Programms und geben Sie Eingaben zurück.
- **Simulationssteuerung** — Pausieren, Zurücksetzen und Beobachten der Simulationsgeschwindigkeit.

Beginnen Sie mit [Kompilieren und Ausführen](/docs/de/programming/compile-and-run/), wenn Sie
verstehen möchten, was passiert, wenn Sie **Play** drücken.
