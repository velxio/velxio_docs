Der Schaltungseditor ist die Arbeitsfläche, auf der Ihr Projekt lebt. Von hier aus können Sie:

- **Add parts** (Teile hinzufügen) aus der Komponentenauswahl, sortiert nach Kategorie und Marke.
- **Wire pins together** (Pins verbinden), indem Sie auf einen Pin klicken und zu einem anderen ziehen.
- **Edit properties** (Eigenschaften bearbeiten) jedes Bauteils – den Widerstandswert, die Farbe einer LED, eine
  I2C-Adresse – über das Eigenschaftenfenster.
- **Read datasheets** (Datenblätter lesen), indem Sie mit der rechten Maustaste auf eine Komponente klicken: Spezifikationen, Pinbelegung und einen
  Link zum Kauf des realen Bauteils.

Die Seiten in diesem Abschnitt behandeln jeden dieser Punkte im Detail, sowie die vollständige
Liste der Tastaturkürzel.
