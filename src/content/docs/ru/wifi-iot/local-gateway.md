По умолчанию симулированная плата выходит в интернет через облачный
шлюз Velxio — но не в вашу локальную сеть. **Локальный сетевой шлюз**
(`velxiogw`) устраняет это ограничение: небольшая программа, которую вы
запускаете на своем компьютере, и трафик платы выходит через нее. Ваш MQTT
брокер, ваш Home Assistant, API, который вы разрабатываете на `localhost` —
все доступно из скетча. Для сопряжения требуется тарифный план Maker.

## Настройка

1. Загрузите шлюз для вашей платформы из
   [последнего релиза](https://github.com/velxio/velxiogw/releases/latest)
   и запустите его:

   ```
   $ ./velxiogw
   velxiogw 0.1.2 — Velxio IoT Network Gateway
     listening on   ws://127.0.0.1:9013
     pairing code   493028
     reach scope    your LAN + localhost + internet
     host alias     host.velxio.internal -> this machine
   ```

2. В редакторе откройте панель **WiFi** (стрелка рядом с иконкой
   WiFi). Панель сама обнаружит запущенный шлюз.

3. Введите **код сопряжения**, который вывел шлюз, и нажмите **Connect**.
   Со следующего запуска плата будет в вашей сети.

При первом запуске Chrome запросит разрешение на доступ страницы к
устройству в вашей локальной сети — нажмите **Allow**. (Safari в настоящее
время не поддерживает это; используйте Chrome, Edge или Firefox.)

## Доступ к вашему компьютеру

Внутри скетча имя хоста `host.velxio.internal` всегда разрешается в
машину, на которой запущен шлюз:

```cpp
#include <HTTPClient.h>

HTTPClient http;
http.begin("http://host.velxio.internal:8000/api/reading");
int status = http.GET();
```

Все остальное в вашей LAN доступно по обычному IP-адресу или имени хоста
без mDNS, точно так же, как с реальной платы в вашей WiFi-сети.

## Примечания

- Шлюз привязывается только к вашему loopback-интерфейсу и отклоняет
  подключения без кода сопряжения, поэтому никто другой в вашей сети —
  или на любой другой веб-странице — не сможет им воспользоваться.
- Трафик через локальный шлюз никогда не касается серверов Velxio и
  обычно быстрее, так как исключает лишний цикл передачи.
- Исходный код открыт на
  [github.com/velxio/velxiogw](https://github.com/velxio/velxiogw);
  бинарные файлы можно скачать бесплатно, а процесс сопряжения в
  редакторе — функция тарифного плана Maker.
- В приложении Velxio Desktop все это не нужно: симуляция уже работает
  на вашем компьютере, поэтому плата в вашей сети по построению.
