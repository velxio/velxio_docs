Когда ваш проект работает в симуляторе, вы можете перенести его на **реальную
плату** без установки чего-либо: Velxio прошивает скомпилированную прошивку
через USB, прямо из браузера.

## Требования

- Браузер на основе Chromium (Chrome или Edge) — прошивальщик использует
  API последовательного порта браузера, которого нет в Firefox и Safari.
- USB-кабель с поддержкой передачи данных для подключения к плате.
- Сначала закройте всё остальное, что использует порт (мониторы последовательного порта, IDE) —
  браузеру нужен монопольный доступ.

## Прошивка

1. Откройте диалог **Flash** (Прошивка) в редакторе.
2. Выберите USB-порт — диалог автоматически определяет кандидатов, и
   браузер попросит вас подтвердить, какой порт разрешить.
3. Velxio использует уже скомпилированную прошивку для вашей платы — тот же
   бинарный файл, который запускал симулятор.
4. Следите за прогрессом; когда процесс завершится, плата перезагрузится в ваш
   проект.

Платы RP2040/RP2350 прошиваются файлом `.uf2`, платы ESP32 — файлом `.bin` —
диалог выбирает правильный протокол для целевого устройства.

## Сначала симуляция, потом прошивка

Это замыкает цикл, который делает Velxio полезным для реальной работы:
быстро итерируйте в симуляторе (без кабеля, без износа оборудования, мгновенные
сбросы), затем прошивайте тот же самый собранный артефакт, когда всё работает.
