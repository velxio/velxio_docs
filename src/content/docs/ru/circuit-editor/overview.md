Редактор схем — это рабочая область, где живет ваш проект. Здесь вы можете:

- **Add parts** (добавлять компоненты) из каталога компонентов, сгруппированных по категориям и брендам.
- **Wire pins together** (соединять выводы) — щелкните по выводу и перетащите его к другому.
- **Edit properties** (редактировать свойства) каждой детали — сопротивление резистора, цвет светодиода,
  I2C-адрес — на панели свойств.
- **Read datasheets** (читать технические описания) — щелкните правой кнопкой мыши по любому компоненту: характеристики, распиновка и
  ссылка для покупки реальной детали.

Страницы этого раздела подробно описывают каждое из этих действий, а также содержат полный
список сочетаний клавиш.
