Нажмите **Add** (Добавить) на панели инструментов (или кнопку **+** на холсте), чтобы открыть
окно выбора компонентов:

![Окно выбора компонентов](../../../../assets/docs/circuit-editor/component-picker.png)

- **Search** (Поиск) по названию или функции: `oled`, `dht`, `resistor`, `servo`…
- **Filter** (Фильтр) по категориям с помощью выпадающего списка справа — платы,
  дисплеи, датчики, двигатели, логика, аналоговые компоненты и фирменные модули.
- Карточки со значком **PRO badge** требуют платного плана для _запуска_ — вы можете
  просматривать весь каталог в любом случае. См. [тарифы](/docs/ru/getting-started/plans/).

Нажмите на карточку, и компонент появится на холсте. Далее:

- **Drag** (Перетаскивание) для перемещения компонента.
- **Click** (Клик) для выбора (пунктирная рамка показывает выделение).
- **Right-click** (Правый клик) для открытия [инспектора компонентов](/docs/ru/circuit-editor/part-inspector/) —
  свойства, назначение выводов, техническое описание, поворот и удаление.
- **Delete** или **Backspace** удаляет выбранный компонент.

Каждый компонент на холсте активен во время симуляции: светодиоды светятся, дисплеи
рисуют, кнопки нажимаются, датчики сообщают значения, которые вы им задали.

Полный каталог, со страницей для каждого компонента, находится в
[справочнике компонентов](/docs/ru/parts/overview/).
