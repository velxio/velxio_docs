## Проект

| Сочетание клавиш | Действие                                  |
| ---------------- | ----------------------------------------- |
| **Ctrl+S**       | Сохранить проект                          |
| **Ctrl+B**       | Скомпилировать код активной платы         |

## Холст

| Сочетание клавиш        | Действие                                        |
| ----------------------- | ----------------------------------------------- |
| **Delete** / **Backspace** | Удалить выбранную деталь или провод           |
| **Escape**              | Отменить прокладку провода                      |
| Правый клик по детали   | Открыть её [инспектор](/docs/ru/circuit-editor/part-inspector/) |

## Цвета проводов

При прокладке или выборе провода — см.
[Подключение](/docs/ru/circuit-editor/wiring/) для палитры:

| Сочетание клавиш | Цвет                                                              |
| ---------------- | ----------------------------------------------------------------- |
| **0–9**          | Чёрный, Коричневый, Красный, Оранжевый, Золотой, Зелёный, Синий, Фиолетовый, Серый, Белый |
| **c**            | Голубой                                                           |
| **l**            | Лаймовый                                                         |
| **m**            | Пурпурный                                                        |
| **p**            | Фиолетовый                                                       |
| **y**            | Жёлтый                                                            |

## Редактор кода

Стандартные сочетания клавиш редактирования, которые вы ожидаете (выделение,
дублирование, переключение комментариев), работают в редакторе кода.

## AI-чат

| Сочетание клавиш | Действие            |
| ---------------- | ------------------- |
| **Enter**        | Отправить сообщение |
| **Shift+Enter**  | Новая строка        |
