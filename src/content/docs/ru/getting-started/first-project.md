Самый быстрый способ понять Velxio — запустить что-нибудь. В этом руководстве
вы откроете классический пример _blink_, запустите его, увидите, как симулированный ESP32
управляет реальной светодиодной схемой, а затем измените код.

## 1. Откройте пример

Перейдите на [velxio.dev/example/esp32-blink-led](https://velxio.dev/example/esp32-blink-led)
(или найдите **ESP32 Blink** в [галерее примеров](/docs/ru/getting-started/examples-gallery/)).

![Пример blink, загруженный в редактор](../../../../assets/docs/getting-started/first-project-loaded.png)

Вы получаете полный проект: **код** слева (скетч Arduino, который
переключает два светодиода) и **схему** в центре — ESP32 DevKit, подключенный
через резистор к внешнему светодиоду.

## 2. Нажмите Run

Нажмите зеленую кнопку **Run** на панели инструментов (или нажмите **Ctrl+B** для
компиляции). Velxio компилирует ваш скетч с помощью реального инструментария Arduino/ESP-IDF
в облаке — консоль **Output** внизу слева показывает
ход компиляции, точно так же, как это делала бы Arduino IDE.

Первая компиляция в сессии может занять некоторое время; после этого сборки
выполняются гораздо быстрее.

## 3. Наблюдайте за работой

Когда сборка завершится, прошивка загрузится на эмулированный ESP32:

![Пример blink в работе: светодиод горит, вывод в последовательный порт](../../../../assets/docs/getting-started/first-project-running.png)

Происходят три вещи одновременно:

- **Светодиод на холсте мигает** — симуляция управляет реальным
  компонентом через реальный резистор.
- **Монитор последовательного порта** показывает журнал загрузки, а затем `LED ON` / `LED OFF`,
  напрямую из `Serial.println()` в скетче.
- Желтый **значок SPICE** над схемой показывает, как аналоговый движок
  вычисляет путь тока через светодиод.

## 4. Сделайте его своим

Отредактируйте скетч — например, измените задержку, чтобы светодиод мигал быстрее:

```cpp
delay(100);   // было 500
```

Нажмите **Run** снова. Вот и весь цикл: редактируйте, запускайте, наблюдайте.

## 5. Сохраните проект

Нажмите **значок сохранения** над деревом файлов (или **Ctrl+S**), дайте
проекту имя, и он будет сохранен в вашей учетной записи. См.
[Сохранение и открытие проектов](/docs/ru/getting-started/projects/).

> **Совет:** застряли на каком-то моменте? Откройте AI-ассистента справа и спросите —
> «почему мой светодиод не мигает?» — это один из его примеров запросов не просто так.
> См. [AI-ассистент](/docs/ru/ai/overview/).
