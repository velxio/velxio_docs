## Строка меню

![Строка меню Velxio: File, Edit, View, Account, Help](../../../../assets/docs/getting-started/interface-menu-bar.png)

**File · Edit · View · Account · Help** — операции с проектом, отмена/повтор,
видимость панелей, ваша учетная запись и тарифный план, справочные ресурсы.

## Панель инструментов

![Панель инструментов редактора: от переключателей макета до кнопки Add](../../../../assets/docs/getting-started/interface-toolbar.png)

Слева направо:

| Элемент управления       | Что делает                                                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Переключатели макета     | Показать редактор **Code**, холст **Circuit** или **Both** рядом друг с другом                              |
| Выбор языка              | **Arduino C++**, **MicroPython** или **ESP-IDF** — для каждой платы, см. [Языки](/docs/ru/programming/languages/) |
| **Compile** (Ctrl+B)     | Собрать без запуска                                                                                         |
| **Run**                  | Скомпилировать при необходимости, затем запустить симуляцию                                                 |
| **Stop** / **Reset**     | Остановить симуляцию / перезапустить прошивку с начала                                                     |
| **Libraries**            | Поиск и установка библиотек Arduino                                                                         |
| Переключатель вывода     | Показать/скрыть консоль вывода компилятора                                                                  |
| Выбор платы              | К какой плате применяются редактор кода и кнопка Run (в проекте может быть несколько плат)                  |
| **Serial**               | Включить/выключить [монитор последовательного порта](/docs/ru/programming/serial-monitor/)                     |
| **Scope**                | Включить/выключить [осциллограф / логический анализатор](/docs/ru/instruments/oscilloscope/)                   |
| **Add**                  | Открыть [выбор компонентов](/docs/ru/circuit-editor/placing-components/)                                       |

## Панель рабочей области (слева)

![Панель рабочей области с деревом файлов проекта](../../../../assets/docs/getting-started/interface-workspace.png)

Дерево файлов вашего проекта: у каждой платы свои файлы (`sketch.ino`,
`libraries.json`, все, что вы добавляете). Значки над деревом создают новую
рабочую область из [стартового шаблона](/docs/ru/getting-started/projects/),
открывают файл проекта и сохраняют.

## Холст (по центру)

![Холст с мигающей схемой ESP32, значком SPICE и элементами управления масштабом](../../../../assets/docs/getting-started/interface-canvas.png)

Здесь находится схема. Прокрутка для панорамирования, элементы управления
масштабом в правом нижнем углу, щелчок по деталям для их выбора, правый
щелчок для [инспектора](/docs/ru/circuit-editor/part-inspector/). Желтый значок
**SPICE** сообщает о состоянии аналогового движка для выбранной схемы.

## Консоли (внизу)

![Консоль вывода и монитор последовательного порта рядом](../../../../assets/docs/programming/serial-monitor.png)

- **Output** — сообщения компилятора и системы.
- **Serial monitor** — по одной вкладке на запущенную плату; поле ввода для
  отправки данных обратно. См. [Монитор последовательного порта](/docs/ru/programming/serial-monitor/).
- **Oscilloscope** — при включении. См.
  [Осциллограф](/docs/ru/instruments/oscilloscope/).

## ИИ-панель (справа)

![ИИ-панель с вкладками Basic, Agent и Tutor и счетчиком кредитов](../../../../assets/docs/getting-started/interface-ai-panel.png)

Помощник в трех режимах — **Basic**, **Agent**, **Tutor** — с вашей
оставшейся дневной квотой внизу. См.
[ИИ-помощник](/docs/ru/ai/overview/). Сверните панель с помощью кнопки со
стрелкой, когда вам нужен весь холст.
