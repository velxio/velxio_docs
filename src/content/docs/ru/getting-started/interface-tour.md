## Строка меню

**File · Edit · View · Account · Help** — операции с проектом, отмена/повтор,
видимость панелей, ваша учетная запись и тарифный план, справочные ресурсы.

## Панель инструментов

Слева направо:

| Элемент управления      | Что делает                                                                                                  |
| ----------------------- | ----------------------------------------------------------------------------------------------------------- |
| Переключатели макета    | Показать редактор **Code** (кода), холст **Circuit** (схемы) или **Both** (оба) рядом                        |
| Выбор языка             | **Arduino C++**, **MicroPython** или **ESP-IDF** — для каждой платы, см. [Языки](/docs/ru/programming/languages/) |
| **Compile** (Ctrl+B)    | Собрать без запуска                                                                                          |
| **Run**                 | Скомпилировать при необходимости, затем запустить симуляцию                                                  |
| **Stop** / **Reset**    | Остановить симуляцию / перезапустить прошивку с начала                                                       |
| **Libraries**           | Поиск и установка библиотек Arduino                                                                          |
| Переключатель вывода    | Показать/скрыть консоль вывода компилятора                                                                   |
| Выбор платы             | К какой плате применяются редактор кода и **Run** (в проекте может быть несколько плат)                      |
| **Serial**              | Включить/выключить [монитор последовательного порта](/docs/ru/programming/serial-monitor/)                     |
| **Scope**               | Включить/выключить [осциллограф / логический анализатор](/docs/ru/instruments/oscilloscope/)                   |
| **Add**                 | Открыть [выбор компонентов](/docs/ru/circuit-editor/placing-components/)                                        |

## Панель рабочей области (слева)

Дерево файлов вашего проекта: у каждой платы свои файлы (`sketch.ino`,
`libraries.json`, а также все, что вы добавите). Значки над деревом создают
новую рабочую область из [стартового шаблона](/docs/ru/getting-started/projects/),
открывают файл проекта и сохраняют.

## Холст (по центру)

Здесь находится схема. Прокручивайте для панорамирования, используйте элементы
управления масштабом в правом нижнем углу, щелкайте по деталям для выбора,
щелкните правой кнопкой мыши для открытия [инспектора](/docs/ru/circuit-editor/part-inspector/).
Желтый значок **SPICE** сообщает о состоянии аналогового движка для выбранной схемы.

## Консоли (внизу)

- **Output** — сообщения компилятора и системные сообщения.
- **Serial monitor** — по одной вкладке на каждую запущенную плату; поле ввода
  для отправки данных обратно. См. [Монитор последовательного порта](/docs/ru/programming/serial-monitor/).
- **Oscilloscope** — при включении. См.
  [Осциллограф](/docs/ru/instruments/oscilloscope/).

## ИИ-панель (справа)

Ассистент в трех режимах — **Basic**, **Agent**, **Tutor** — с вашей
оставшейся дневной квотой внизу. См.
[ИИ-ассистент](/docs/ru/ai/overview/). Сверните панель с помощью кнопки со стрелкой,
когда вам нужен весь холст.
