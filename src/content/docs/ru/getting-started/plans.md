Velxio бесплатен в использовании, и бесплатный тариф — это не демо-версия.
Редактор схем, редактор кода, каталог компонентов, галерея примеров и
неограниченное количество публичных проектов ничего не стоят, и ни одна
плата не скрыта от вас.

Платные тарифы существуют для двух вещей, которые требуют реальных денег
на поддержку — **AI-ассистента**, где каждый запрос — это вызов модели, и
**серверной эмуляции**, где платы STM32 и Raspberry Pi работают как
настоящие процессы QEMU на машинах Velxio — а также для функций,
предназначенных для тех, кто использует Velxio для работы: приватные
проекты, экспорт, интеграции и офлайн-десктоп-приложение.

Тарифы аддитивны: **Pro включает всё, что есть в Maker, который включает
всё, что есть в Free.**

того же тарифа. Оба варианта доступны при оформлении заказа с помощью
карты (Stripe) или PayPal.

## AI-ассистент

У ассистента есть три режима, и они не одинаково ограничены.

| Режим | Что делает | Тарифы |
| --- | --- | --- |
| **Basic** | Отвечает на вопросы, используя ваш проект как контекст — «почему мой светодиод не горит?», «что означает эта ошибка компилятора?» Он читает холст и код, но не изменяет их. | Все тарифы, включая Free |
| **Agent** | Действует в проекте: добавляет и подключает компоненты, пишет и исправляет код, запускает симуляцию для проверки своей работы. | Maker и Pro |
| **Tutor** | Обучает шаг за шагом на вашей собственной схеме — предлагает упражнения, проверяет, что вы собрали, объясняет теорию. | Maker и Pro |

Режим Basic на бесплатном тарифе имеет **собственный пул из 50 сообщений
в день**, который не расходует ваши AI-кредиты. Таким образом, бесплатная
учетная запись не ограничена 20 AI-взаимодействиями в день — она получает
50 сообщений Basic-чата плюс 20 кредитов.

### Как считаются AI-кредиты

Кредиты (показаны как счетчик внизу панели чата) измеряют работу, которую
выполняют режимы Agent и Tutor:

- Обычный запрос стоит **1 кредит**.
- Большой запрос — тот, который отправляет более примерно 30,000 токенов
  контекста, например, длинный разговор над большим скетчем — стоит
  пропорционально больше, поэтому один тяжелый запрос может потратить
  несколько кредитов.
- Дневной счетчик **сбрасывается в полночь по UTC**. Неиспользованные
  кредиты не переносятся.
- Месячный максимум — это второй, независимый лимит поверх дневного.
- Встроенные завершения кода в редакторе тарифицируются отдельно и
  никогда не расходуют кредиты агента.

Смотрите [раздел об AI-ассистенте](/docs/ru/ai/overview/) для получения
информации о том, что может делать каждый режим.

## Платы и симуляция

**Каждая плата в каталоге видна и доступна для редактирования на любом
тарифе**, и большинство из них также *работают* на любом тарифе. Два
семейства являются исключением, потому что их размещение дорого:

| Семейство плат | Где работает | Free | Платные |
| --- | --- | --- | --- |
| Arduino / AVR, RP2040 / RP2350 (Pico, Badger 2350) | Ваш браузер | Да, без лимита времени | Да |
| Семейство ESP32 (classic, S3, C3, C6), M5Stack, XIAO | Серверы Velxio | Да, 1 час на запуск | Да, без лимита на запуск |
| **STM32** (Blue Pill, Black Pill, F4 Discovery…) | Серверы Velxio | Нет | Да |
| **Raspberry Pi Linux** (Zero, 1, 2, 3, 4, 5, UNIHIKER) | Серверы Velxio | Нет | Да |

Платы, требующие платного тарифа, — это именно семейство STM32 и
семейство Raspberry Pi Linux — они имеют **значок PRO** в выборе
компонентов. Фирменные платы, такие как M5Stack Cardputer, Pimoroni
Badger 2350 или семейство XIAO, **не** являются платными, даже если они
являются частью размещенного каталога.

Два ограничения применяются ко всем, включая платных пользователей:

- Симуляция, оставленная **бездействующей на 2 часа**, останавливается
  автоматически.
- Сеанс Raspberry Pi имеет **жесткий лимит в 2 часа** на сеанс.

Некоторые отдельные функции также требуют платного тарифа: эмуляция WiFi
для Pico W, загрузка файлов на смоделированную microSD-карту, приватный
IoT-шлюз и небольшой набор премиальных компонентов (они показывают значок
PRO в выборе).

## Проекты и публикация

| | Free | Maker | Pro |
| --- | --- | --- | --- |
| Публичные проекты (в галерее) | Безлимитно | Безлимитно | Безлимитно |
| Проекты по ссылке (только по ссылке, скрыты из галереи) | Нет | Да | Да |
| Приватные проекты (только вы) | Нет | Нет | Да |
| Встраивание без значка «Powered by Velxio» | Нет | Нет | Да |
| История симуляции и воспроизведение | Нет | Нет | Да |

Если платный тариф истекает, **ничего не удаляется**. Проекты, которые
уже являются приватными или по ссылке, сохраняют эту видимость — вы просто
не можете создавать новые или изменять видимость проекта, пока не
подпишетесь снова.

## Библиотеки и компиляция

Компиляция с помощью `arduino-cli` и установка библиотек через Library
Manager работает на любом тарифе. Меняется только хранилище и способ
попадания библиотек:

| | Free | Maker | Pro |
| --- | --- | --- | --- |
| Library Manager + компиляция | Да | Да | Да |
| Хранилище для установленных и загруженных библиотек | 100 МБ | 500 МБ | 2 ГБ |
| Загрузка собственной библиотеки в виде `.zip` | Нет | Да | Да |
| Приоритетная очередь компиляции в пиковые часы | Нет | Да | Да |

Смотрите [Библиотеки](/docs/ru/programming/libraries/) для получения
информации о том, как считается квота.

## Самостоятельное размещение

Velxio имеет открытый исходный код под лицензией AGPLv3, и размещенное
приложение на velxio.dev построено из того же исходного кода. Вы можете
запустить его самостоятельно бесплатно — платные тарифы финансируют
размещенный сервис, серверы эмуляции и AI-провайдеров, стоящих за ним.
