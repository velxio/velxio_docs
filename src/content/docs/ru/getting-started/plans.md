Вы можете создавать, моделировать и делиться схемами на Velxio **бесплатно** —
основной симулятор, открытый каталог плат, галерея примеров и публичные
проекты не стоят ничего.

Платные тарифы (**Maker** и **Pro**) открывают функции, которые требуют реальных
вычислительных ресурсов или предназначены для продвинутых пользователей:

| Функция                                                                                 | Бесплатно | Платные тарифы           |
| --------------------------------------------------------------------------------------- | --------- | ------------------------ |
| Редактор схем, редактор кода, симуляция                                                 | Да        | Да                       |
| Открытые платы (Arduino, семейство ESP32, Pico, STM32, ATtiny…)                         | Да        | Да                       |
| Галерея примеров, публичные проекты                                                     | Да        | Да                       |
| **Pro-платы** (семейство Raspberry Pi Linux, M5Stack Cardputer, Badger 2350, XIAO Sense…) | Нет       | Да                       |
| **ИИ-ассистент** (Basic / Agent / Tutor)                                                | Нет       | Да, с квотами по тарифам |
| **Приватные проекты**                                                                   | Нет       | Да                       |
| Приоритет компиляции и более высокие лимиты использования                               | Нет       | Да                       |

Платы и компоненты, требующие платного тарифа, отмечены **PRO-значком**
в выборе компонентов — вы всегда можете видеть весь каталог.

ИИ-ассистент учитывает использование в **циклах** (показано внизу
панели чата, с дневными и месячными лимитами, которые зависят от вашего тарифа).

Актуальные цены и полное сравнение смотрите на
[странице тарифов](https://velxio.dev/pricing). Чтобы оформить подписку или
управлять ею, см. [Подписка](/docs/ru/account/overview/).
