Velxio не имитирует MicroPython — он загружает **настоящую прошивку
MicroPython** на эмулируемый чип. `import machine` работает так же, как
на реальном оборудовании, а [последовательный монитор](/docs/ru/programming/serial-monitor/)
выступает в роли REPL.

## Попробуйте в один клик

Откройте пример «ночник» из галереи — фоторезистор (LDR),
управляющий светодиодом, на чистом MicroPython:

![Пример «ночник» на MicroPython](../../../../assets/docs/programming/micropython-editor.png)

Обратите внимание на панель инструментов: селектор языка показывает **MicroPython**, а
в дереве файлов отображается `main.py` вместо скетча. Нажмите **Run** (Запуск):

![Ночник в работе — перетащите LDR и наблюдайте за светодиодом](../../../../assets/docs/programming/micropython-running.png)

Пока он работает, щёлкните по **фоторезистору** и перетащите его уровень освещённости —
показания АЦП изменятся, и светодиод переключится ровно так, как решает код.

## Основы

```python
from machine import Pin, ADC
import time

led = Pin(4, Pin.OUT)
ldr = ADC(Pin(34))

while True:
    if ldr.read() < 1000:   # темно
        led.on()
    else:
        led.off()
    time.sleep_ms(200)
```

- **`machine.Pin` / `ADC` / `PWM` / `I2C` / `SPI`** — управляйте теми же
  симулируемыми периферийными устройствами, что и в скетчах Arduino.
- **REPL** — остановите свой скрипт и вводите команды Python в интерактивном режиме в
  последовательном мониторе; `help()` работает, автодополнение по табуляции тоже работает.
- **WiFi** — на платах ESP32 `network.WLAN` подключается к `Velxio-GUEST` так же, как
  на реальном оборудовании: см. [ESP32 WiFi](/docs/ru/wifi-iot/esp32-wifi/).
- **Дополнительные модули** — добавляйте файлы на чистом Python рядом с `main.py` и
  импортируйте их; см. [Использование библиотек](/docs/ru/programming/libraries/).

## Какие платы

MicroPython доступен на Raspberry Pi **Pico / Pico W** (его родная
среда) и во всём **семействе ESP32** — полная матрица приведена в разделе
[Языки](/docs/ru/programming/languages/). Переключите любую поддерживаемую плату на
MicroPython с помощью селектора языка на панели инструментов; Velxio сам заменит
набор файлов.
