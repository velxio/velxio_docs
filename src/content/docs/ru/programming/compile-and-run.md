## Что делает Run

**Run** компилирует код активной платы (при необходимости) и запускает результат
на эмулируемой плате. Здесь нет «симуляции вашего исходного кода» —
Velxio собирает **настоящий бинарный файл прошивки** с реальным инструментарием
(arduino-cli / ESP-IDF / MicroPython) и выполняет его инструкция за
инструкцией.

- **Compile** (Ctrl+B) выполняет сборку без запуска — удобно для быстрой
  проверки ошибок.
- **Stop** останавливает симуляцию; **Reset** перезагружает прошивку с
  самого начала.

## Консоль вывода

Панель **OUTPUT** внизу слева отображает процесс сборки: разрешение библиотек,
вызовы компилятора, использование памяти и, наконец,
`Compilation successful`. Это тот же вывод, который вы получили бы в Arduino IDE
или при выполнении `idf.py build`.

## Чтение ошибок компиляции

Ошибки приходят точно в том виде, в котором их выдает компилятор, с указанием файла и строки:

- `'foo' was not declared in this scope` — опечатка или отсутствует `#include`.
- `No such file or directory` для заголовочного файла — библиотека не установлена;
  добавьте её через **Libraries** ([как](/docs/ru/programming/libraries/)).
- Ошибки компоновщика/секций для больших скетчей — бинарный файл не помещается
  во flash выбранной платы.

Исправьте и нажмите **Run** снова. Сборки после первой выполняются гораздо быстрее
благодаря кэшированию.

> **Tip:** вставьте ошибку компиляции в [AI-ассистента](/docs/ru/ai/overview/)
> — объяснение ошибок в контексте — это то, что его базовый режим умеет лучше всего.

## Во время выполнения

- **Status dot** рядом с именем платы в дереве файлов показывает
  Idle / Compiled / Running.
- **Serial monitor** подключается автоматически —
  см. [Serial monitor](/docs/ru/programming/serial-monitor/).
- Взаимодействуйте со схемой в реальном времени: нажимайте кнопки, вращайте
  потенциометры, изменяйте значения датчиков с их панелей управления.
