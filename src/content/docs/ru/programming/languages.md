**Селектор языка** на панели инструментов переключает способ написания и сборки кода для активной платы. Переключение языка заменяет набор файлов рабочей области (`sketch.ino` становится `main.py` и так далее).

## Arduino C++

По умолчанию почти везде: классические скетчи `setup()` / `loop()`, компилируемые с помощью реального инструментария Arduino для целевой платы. Используйте кнопку **Libraries** (Библиотеки), чтобы добавить любую опубликованную библиотеку Arduino — см. [Библиотеки](/docs/ru/programming/libraries/).

Доступен на всех платах, кроме семейства Linux Raspberry Pi.

## MicroPython

Настоящая прошивка MicroPython, работающая на эмулированном чипе — REPL работает через последовательный монитор, `import machine` и другие модули ведут себя так же, как на реальном оборудовании.

Доступен на:

- **Raspberry Pi Pico / Pico W** (RP2040)
- **ESP32 classic** — DevKit V1, DevKit-C v4, ESP32-CAM, Lolin32 Lite
- **ESP32-S3** — DevKit, XIAO ESP32-S3, Arduino Nano ESP32
- **ESP32-C3** — DevKit, XIAO ESP32-C3, C3 SuperMini

## ESP-IDF

Чистые проекты ESP-IDF (точка входа `app_main()`, API IDF, без ядра Arduino), компилируемые с помощью того же инструментария ESP-IDF. Для случаев, когда вы пишете код, который будете прошивать в производстве.

Доступен на тех же платах семейства ESP32, что и MicroPython выше.

## Python на Linux (Raspberry Pi)

Платы Linux Raspberry Pi (от Zero до 5) не используют селектор языка: они загружают полноценный Linux, и вы работаете в настоящей оболочке — запускаете Python с `gpiozero`/`RPi.GPIO` для работы с симулированными GPIO, точно так же, как на физической Pi. См. [страницы плат](/docs/ru/boards/overview/).
