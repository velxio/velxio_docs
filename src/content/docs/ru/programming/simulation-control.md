## Запуск / Остановка / Сброс

Три транспортные кнопки на панели инструментов:

- **Run** (Запуск) — компиляция при необходимости, загрузка прошивки, запуск мира.
- **Stop** (Остановка) — остановка симуляции. Схема сохраняет свой вид, но
  ничего не выполняется.
- **Reset** (Сброс) — перезагрузка прошивки с начала без повторной компиляции.

Индикатор состояния рядом с именем платы в дереве файлов отслеживает состояние:
Idle (Простой), Compiled (Скомпилировано), Running (Выполняется).

## Взаимодействие во время работы

Холст активен во время симуляции:

- **Кнопки и переключатели** реагируют на щелчки.
- **Потенциометры, энкодеры и датчики** предоставляют элементы управления для изменения их
  значений — температуру DHT22, уровень освещенности LDR — и прошивка
  видит изменение немедленно.
- **Дисплеи, светодиоды и двигатели** отображают свое реальное управляемое состояние.

Изменения свойств из [инспектора компонентов](/docs/ru/circuit-editor/part-inspector/)
также применяются в реальном времени.

## Несколько плат

Проект может содержать **более одной платы**, каждая со своим кодом, вкладкой
Serial (Последовательный порт) и состоянием Run (Запуск) — селектор плат на панели инструментов выбирает, на какую
нацелены редактор кода и транспортные кнопки. Платы могут общаться друг с
другом через проводные шины — именно так работают примеры с несколькими чипами.

## Аналоговый движок

Активность цифровых выводов и аналоговые компоненты решаются вместе: желтый
**значок SPICE** над схемой показывает размер аналоговой сети и время
решения. Когда схема может повредить компонент (светодиод без последовательного
резистора в электрическом режиме), верификатор отмечает это до начала запуска — исправьте
соединения или значение и запустите снова.
