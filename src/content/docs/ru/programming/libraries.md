Нажмите **Libraries** (Библиотеки) на панели инструментов, чтобы выполнить поиск в реестре библиотек Arduino
и добавить библиотеки на активную плату.

Установленные библиотеки записываются в файл **`libraries.json`** платы
(виден в дереве файлов), поэтому они перемещаются вместе с проектом: любой, кто
откроет его — включая вас в будущем — получит те же версии, разрешённые на
этапе компиляции. Никакой отдельной папки библиотек на каждой машине, которую нужно синхронизировать.

## Использование библиотеки

Установите её, затем используйте `#include` как обычно:

```cpp
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
```

Облачный компилятор загружает объявленные библиотеки (а также их
зависимости) перед сборкой. Если сборка завершается ошибкой
`No such file or directory` для заголовочного файла, это означает, что библиотека, предоставляющая этот
заголовочный файл, ещё не объявлена — добавьте её через **Libraries** (Библиотеки).

## MicroPython

Прошивка MicroPython поставляется со стандартными встроенными модулями
(`machine`, `network`, `time`, …). Чисто Python-модули-помощники можно добавить
как дополнительные файлы в дереве файлов рядом с `main.py` и импортировать обычным способом.

## Примеры уже настроены

Каждый пример из галереи объявляет необходимые ему библиотеки — открыв один из них,
вы получаете проверенную комбинацию кода, схемы и версий библиотек, что делает
их хорошей отправной точкой для ваших собственных проектов.
