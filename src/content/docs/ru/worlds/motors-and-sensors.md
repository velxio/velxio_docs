World никогда не выполняет ваш код и никогда не трогает вывод напрямую. Он считывает
то, что задаёт цепь, и записывает то, что измерили бы датчики, поэтому
прошивка — это тот же код, который работает на реальном роботе.

## Что считывает World

| Компонент                               | Значение, которое получает World                              |
| --------------------------------------- | ------------------------------------------------------------- |
| Коллекторный двигатель, мотор-редуктор с энкодером | `drive`, от -1 до 1: скважность на двигателе, знак = направление |
| Серво                                   | `angle`, от 0 до 180 градусов                                 |
| Светодиод                               | `on` (true, когда горит) и `brightness`, от 0 до 1 (следует за PWM) |

Drive двигателя считывается через то, что им управляет: L293D, транзистор или
MOSFET, встроенный драйвер платы (платы Romeo) или вывод напрямую к
двигателю. Сторона робота следует среднему drive своих двигателей, с небольшой
инерцией (около 80 мс) и небольшим мёртвым ходом, как у настоящей коробки передач.

Светодиод ничего не двигает, но World, который вы напишете сами, может его нарисовать: светофор
на перекрёстке, маяк, лампа в комнате.

## Что записывает World

| Компонент                              | Значения                                                   | Как это читает прошивка                                       |
| -------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| DFRobot Gravity датчик линии (SEN0017) | отражательная способность от 0 до 1, `black`               | `digitalRead(pin) == LOW` над чёрной лентой                   |
| DFRobot URM09, режим Trig (SEN0388)    | расстояние, от 2 до 500 см                                 | один вывод: триггер 10 мкс, затем `pulseIn(pin, HIGH) / 58.0` |
| DFRobot URM37 V5.0, режим PWM          | расстояние, от 2 до 500 см                                 | притянуть COMP/TRIG к низкому, затем `pulseIn(ECHO, LOW) / 50` |
| HC-SR04                                | расстояние, от 2 до 400 см                                 | TRIG высокий 10 мкс, затем `pulseIn(ECHO, HIGH) / 58.0`       |
| MPU6050                                | ускорение в g, вращение в градусах в секунду               | I2C, как на реальной микросхеме                               |

Датчики расстояния смотрят прямо вперёд от бампера робота, с узким
конусом около 12 градусов в каждую сторону. Датчики линии считывают коврик (или рампу)
прямо под собой.

## Управление роботом: сторона прошивки

Знак drive определяет направление. Если какая-то сторона в World крутится
в обратную сторону, либо исправьте прошивку, либо поставьте галочку **Reverse** для этой стороны в
[редакторе сцены](/docs/ru/worlds/scene-editor/).

### L293D (любая плата)

Канал 1: EN1 (PWM) с IN1 и IN2, выходы OUT1 и OUT2. Канал 2: EN2
с IN3 и IN4. IN1 HIGH и IN2 LOW — положительный drive, а скважность на
EN1 задаёт скорость.

```cpp
// Arduino Uno: left motor on channel 1, right motor on channel 2
const int EN_L = 5, IN1 = 4, IN2 = 7;
const int EN_R = 6, IN3 = 8, IN4 = 12;

void side(int en, int a, int b, int speed) {   // speed -255..255
  digitalWrite(a, speed >= 0 ? HIGH : LOW);
  digitalWrite(b, speed >= 0 ? LOW : HIGH);
  analogWrite(en, min(abs(speed), 255));
}

void drive(int left, int right) {
  side(EN_L, IN1, IN2, left);
  side(EN_R, IN3, IN4, right);
}
```

### DFRobot Romeo BLE и Romeo BLE mini

M1: направление D4, PWM D5. M2: направление D7, PWM D6. Подключите каждый двигатель к
клеммам платы M1+/M1- или M2+/M2-.

```cpp
void side(int dirPin, int pwmPin, int speed) {
  digitalWrite(dirPin, speed >= 0 ? HIGH : LOW);
  analogWrite(pwmPin, min(abs(speed), 255));
}
void drive(int left, int right) { side(4, 5, left); side(7, 6, right); }   // M1 left, M2 right
```

Библиотека DFRobot DFMobile (используется в примерах Devastator) управляет
выводом направления LOW для движения вперёд с `Robot.Direction(LOW, HIGH)`, поэтому роботу,
работающему на ней, нужен **Reverse** с обеих сторон.

### DFRobot Romeo ESP32-S3

Четыре драйвера DRV8876 в режиме PH/EN. M1 EN 12 / PH 13, M2 14 / 21, M3 9 / 10,
M4 47 / 11. PH HIGH — вперёд.

```cpp
const int EN[4] = { 12, 14, 9, 47 }, PH[4] = { 13, 21, 10, 11 };
void motor(int i, int speed) {
  digitalWrite(PH[i], speed >= 0 ? HIGH : LOW);
  analogWrite(EN[i], min(abs(speed), 255));
}
void drive(int left, int right) { motor(0, left); motor(2, left); motor(1, right); motor(3, right); }
```

### Транзистор или MOSFET

Только одно направление: скважность на выводе затвора и есть drive.

## Поведения

Движение по линии на трёх датчиках:

```cpp
bool L = digitalRead(LINE_L) == LOW, C = digitalRead(LINE_C) == LOW, R = digitalRead(LINE_R) == LOW;
if (C && !L && !R) drive(150, 150);        // on the line
else if (L)        drive(40, 170);         // tape on the left: turn left
else if (R)        drive(170, 40);         // tape on the right: turn right
else               drive(-80, 80);         // lost: spin and look for it
```

Обходчик препятствий едет вперёд, а на расстоянии от 20 до 35 см останавливается, отъезжает
и поворачивает в сторону, где больше места (сонар на серво может сначала посмотреть на 0
и 180 градусов). Считывайте сонар каждые 50–100 мс и никогда не блокируйте надолго
в `loop()`.

На полном drive 2WD-робот развивает 0,55 м/с, 4WD — 0,61 м/с, а танк —
0,36 м/с. Для движения по линии на ленте 22 мм значение от 120 до 170 из 255 удерживает его
на линии.
