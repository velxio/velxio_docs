Velxio CI запускает ваш проект на нашем симуляторе вне браузера:
из вашего терминала, задачи GitHub Actions, любого CI, способного запустить бинарник. Плата
загружает вашу реальную скомпилированную прошивку, последовательный вывод транслируется обратно,
а команда завершается с ненулевым кодом, когда что-то из запрошенного не произошло.

```bash
curl -fsSL https://velxio.dev/ci/install.sh | sh
velxio-cli login                           # approve in the browser, once
cd firmware/blink
velxio-cli run --expect-text "Hello, world!" --timeout 10000 .
```


## Для чего это нужно

- **Поймать регрессию прошивки раньше, чем это сделает железо.** Тест, который загружает
  бинарник и ждёт строку из последовательного порта, — это одна команда; тест, который нажимает
  кнопку, задаёт датчик и проверяет пин, — это короткий YAML-файл.
- **Тестировать то, что нельзя держать на столе.** Каждая плата, которую симулирует Velxio,
  доступна каждой задаче, параллельно, без лаборатории и без прошивки.
- **Сохранить свой инструментарий.** Компилируйте с помощью arduino-cli, ESP-IDF,
  PlatformIO или cargo на предыдущем шаге; Velxio запускает только то, что получилось.

## Сколько это стоит

CI тарифицируется в **симулированных минутах** — время, которое, по мнению гостевой прошивки,
прошло, а не то, сколько времени заняли наши серверы. 10-секундный тест стоит 10 секунд
на каждой плате, независимо от того, быстрее или медленнее реального времени его выполнил эмулятор.

| План  | CI-минут в месяц     | Одновременных задач | Максимальный запуск |
| ----- | -------------------- | ------------------- | ------------------- |
| Free  | —                    | —                   | —                   |
| Maker | 200                  | 1                   | 5 мин               |
| Pro   | 2,000                | 2                   | 10 мин              |

Запуск, который так и не начался (неизвестная плата, прошивка, не соответствующая
плате, отклонённый сценарий), ничего не стоит. Минуты сбрасываются первого числа
месяца по UTC. Ваш баланс, история запусков и токены находятся на
[/account/ci](https://velxio.dev/account/ci):

![Страница аккаунта CI: использованные за месяц минуты, существующие токены с указанием времени последнего использования каждого и таблица недавних запусков с их статусом, симулированными и оплаченными секундами и кодом выхода](../../../../assets/docs/ci/account.png)

## Как проект описывает себя

Два файла в каталоге, на который вы указываете CLI:

- `velxio.toml` — плата и прошивка. Подойдёт и Wokwi `wokwi.toml`.
- `diagram.json` — схема. Формат Wokwi, поэтому существующая схема запускается
  без изменений.

Добавьте `scenario.yaml`, когда проверки последовательного порта недостаточно: он может ждать текст,
отправлять текст, ждать по симулированным часам, проверять пин и задавать управление на
компоненте. См. [Сценарии](/docs/ru/ci/scenarios/).
