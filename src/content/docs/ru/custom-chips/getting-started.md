**Пользовательская микросхема** — это компонент, который вы программируете сами. Вы пишете простой код на C с использованием API `velxio-chip.h`, Velxio компилирует его в WebAssembly в облаке, и результат ведет себя как любой каталоговый компонент: у него есть выводы для подключения, атрибуты для редактирования и логика, которая выполняется внутри симуляции.

## Когда стоит создавать такую микросхему

- Нужной ИС нет в каталоге (редкий сдвиговый регистр, проприетарный протокол датчика).
- Вам нужен тестовый стенд — генератор импульсов, имитатор протокола, поддельный датчик с заданными значениями.
- Вы преподаете цифровую логику и хотите, чтобы студенты _реализовали_ микросхему, а не просто использовали ее.

## Версия на пять минут

1. Откройте [выбор компонентов](/docs/ru/circuit-editor/placing-components/) и добавьте **Custom Chip** на холст.
2. Откройте редактор микросхемы (щелкните правой кнопкой мыши по микросхеме). Вы получите два файла:
   - **C source** — поведение;
   - **`chip.json`** — манифест: имя, выводы, атрибуты.
3. Начните со встроенного примера **Inverter**:

```c
#include "velxio-chip.h"
#include <stdlib.h>

typedef struct { vx_pin in, out; } chip_state_t;

static void on_in_change(void* ud, vx_pin pin, int value) {
  chip_state_t* s = ud;
  vx_pin_write(s->out, value ? VX_LOW : VX_HIGH);
}

void chip_setup(void) {
  chip_state_t* s = malloc(sizeof *s);
  s->in  = vx_pin_register("IN",  VX_INPUT);
  s->out = vx_pin_register("OUT", VX_OUTPUT);
  vx_pin_write(s->out, vx_pin_read(s->in) ? VX_LOW : VX_HIGH);
  vx_pin_watch(s->in, VX_EDGE_BOTH, on_in_change, s);
  vx_log("inverter ready");
}
```

с его манифестом:

```json
{
  "schema": "velxio-chip/v1",
  "name": "Inverter",
  "pins": ["IN", "OUT", "GND", "VCC"],
  "attributes": []
}
```

4. Нажмите **Compile** (Компилировать) в диалоговом окне — ошибки возвращаются так же, как у любого компилятора C.
5. Подключите `IN` к кнопке, а `OUT` к светодиоду, нажмите **Run** (Запуск) и переключайте.

## Как выполняются микросхемы

Хост вызывает вашу `chip_setup()` один раз для каждого экземпляра микросхемы. После этого микросхема **реактивна**: ваш код выполняется только внутри обратных вызовов — изменился отслеживаемый вывод, пришел байт по I2C, сработал таймер. Здесь нет главного цикла, который можно блокировать, — именно поэтому пользовательские микросхемы достаточно дешевы, чтобы размещать их по всей схеме.

## Встроенные примеры микросхем

В редакторе микросхем есть готовые исходники, которые можно загружать и изменять: логические элементы (инвертор, XOR), сдвиговые регистры (74HC595, CD4094), компоненты I2C (PCF8574, DS3231 RTC, EEPROM 24Cxx), АЦП по SPI (MCP3008), UART-преобразователь ROT13, счетчик импульсов — а также **коллекция ретро-процессоров** (Intel 4004 и другие) для самых отважных.

Далее: [справочник по API микросхем](/docs/ru/custom-chips/api/).
