Пользовательский чип может быть **программируемым датчиком**: компонентом, выход которого вы управляете с помощью ползунка *во время симуляции*. Представьте датчик CO2, чьи ppm вы изменяете для проверки пороговых значений, датчик температуры/влажности за I2C, датчик света, потенциометр с собственным мнением — всё, где вопрос «что если значение изменится?» является главным.

## Рецепт

Три ингредиента, все в чипе, который вы уже умеете писать:

1. **Атрибут** — настраиваемое значение: `vx_attr_register("ppm", 1000)`.
2. **Раздел `controls`** в `chip.json` — именно он выводит ползунок на экран во время симуляции:

```json
{
  "name": "CO2 Sensor",
  "pins": ["VCC", "GND", "OUT"],
  "attributes": [
    { "name": "ppm", "label": "CO2 (ppm)", "type": "int",
      "default": 1000, "min": 400, "max": 5000, "step": 10 }
  ],
  "controls": [
    { "id": "ppm", "label": "CO2 (ppm)", "type": "range",
      "min": 400, "max": 5000, "step": 10, "unit": "ppm" }
  ]
}
```

3. **Перечитывайте атрибут внутри колбэка или таймера** — никогда не кэшируйте его, ползунок изменяет его на лету:

```c
#include "velxio-chip.h"

typedef struct { vx_pin out; vx_attr ppm; vx_timer t; } chip_state_t;
static chip_state_t S;

static void on_tick(void *ud) {
  double ppm = vx_attr_read(S.ppm);              /* live slider value */
  double volts = (ppm - 400.0) / 4600.0 * 5.0;   /* 400..5000 -> 0..5 V */
  vx_pin_dac_write(S.out, volts);
}

void chip_setup(void) {
  S.out = vx_pin_register("OUT", VX_ANALOG);
  S.ppm = vx_attr_register("ppm", 1000);
  S.t = vx_timer_create(on_tick, 0);
  vx_timer_start(S.t, 50000000ULL, true);        /* 50 ms, nanoseconds */
  on_tick(0);
}
```

Подключите `OUT` к аналоговому пину платы (например, Arduino `A0`), нажмите **Run** (Запуск) и кликните на чип: откроется панель ползунка. Перетащите его, и `analogRead(A0)` будет отслеживать изменения в реальном времени.

## Как части соединяются

- Каждая запись `controls` управляет **атрибутом с тем же id** — `vx_attr_read` возвращает новое значение в тот момент, когда ползунок двигается.
- `type: "range"` — это ползунок; `type: "button"` отправляет кратковременный импульс `1 → 0` (около 150 мс) для входов триггера/сброса.
- Нет раздела `controls`? Любой атрибут, объявляющий и `min`, и `max`, автоматически получает живой ползунок — большинство существующих чипов настраиваются без изменения их манифеста.
- `unit` (отображается после значения) и `scale: "log"` — необязательные дополнения для ползунков.
- Значения по умолчанию на этапе проектирования находятся в инспекторе компонентов (правый клик по чипу в остановленном состоянии).

## Готовые шаблоны

В галерее примеров есть два датчика, созданных именно так:

- **CO2 Sensor (live slider)** — аналоговый рецепт выше, дословно.
- **I2C Env Sensor (live sliders)** — температура + влажность за картой регистров I2C по адресу `0x44`, оба управляются ползунками; образец для любого датчика с цифровым протоколом.

Сохраните свой вариант в [My Chips](/docs/ru/custom-chips/my-chips/) — и он будет в один клик в каждом проекте.
