Если вы писали пользовательские чипы для Wokwi, они переносятся без проблем: Velxio
**совместим на уровне исходного кода** с документированным C API пользовательских чипов Wokwi.

## Тот же C, без изменений

`#include "wokwi-api.h"` разрешается в заголовочный файл совместимости, созданный с нуля,
который адаптирует каждый документированный символ к нативному API Velxio `vx_*` на
этапе компиляции:

- `chip_init()` — точка входа, точно так же, как в Wokwi.
- `pin_init`, `pin_read`, `pin_write`, `pin_mode`, `pin_watch` (с его
  `pin_watch_config_t`), `pin_adc_read`, `pin_dac_write` — всё на месте.
- `i2c_init`, `uart_init`, `spi_init` принимают свои структуры конфигурации; поля
  (`connect`/`read`/`write`/`disconnect`, `rx_data`/`write_done`,
  `done`) переводятся один к одному.
- `attr_init` / `attr_read` (и варианты `_float` и строковые),
  `timer_init` / `timer_start` (микросекунды, конвертируются автоматически) /
  `timer_start_ns` / `timer_stop`, `get_sim_nanos`,
  `framebuffer_init` / `buffer_write` / `buffer_read`.
- `INPUT`/`OUTPUT`/`INPUT_PULLUP`/`INPUT_PULLDOWN`/`ANALOG`,
  `OUTPUT_LOW`/`OUTPUT_HIGH`, `LOW`/`HIGH`, `RISING`/`FALLING`/`BOTH`,
  `NO_PIN` — идентичные значения.

Компилируйте как любой чип Velxio: вставьте C-код в `chip.c` пользовательского чипа
и нажмите **Run** (Запуск).

## Совместимость с chip.json

`name`, позиционный массив `pins` (с пропусками слотов `""`),
`attributes`, `controls` (интерактивные ползунки) и `display` работают так же, как
в Wokwi. `symbol` и пользовательские SVG-изображения игнорируются — Velxio рисует
собственный универсальный корпус чипа, размер которого соответствует количеству ваших выводов.

## ZIP-архивы проектов

**File → Open project** (Файл → Открыть проект) принимает ZIP-архив проекта Wokwi. Часть
`chip-<name>` в `diagram.json` становится пользовательским чипом с исходниками,
загруженными из соседних `<name>.chip.c` / `<name>.chip.json`, провода сохраняются.
Экспорт записывает ту же структуру обратно.

## Что не переносится

- **Предкомпилированные `.wasm`-бинарники** — пространство имён импорта Velxio отличается;
  перекомпилируйте из исходников (это занимает секунды, и импорт ZIP-архива делает это
  при первом запуске).
- Экспериментальный API интроспекции `_mcu_*`.

## Для новых чипов предпочтителен нативный API

Слой совместимости существует, чтобы ваши существующие наработки работали. Для новых
чипов нативный [API `velxio-chip.h`](/docs/ru/custom-chips/api/) — это
тот же набор идей с более понятными типами (напряжения как `double`, таймеры
в наносекундах) — и именно на нём говорят примеры, AI-агент и
[My Chips](/docs/ru/custom-chips/my-chips/).
