Оригинальный двухъядерный Xtensa ESP32 — рабочая лошадка каталога, с
**WiFi и Bluetooth**, доступными в симуляторе.

| Плата                   | Особенности                                      |
| ----------------------- | ------------------------------------------------ |
| **ESP32 DevKit V1**     | Стандартный 30-контактный девкит; встроенный светодиод на GPIO2 |
| **ESP32 DevKit-C V4**   | Официальный девкит Espressif, 38 GPIO            |
| **ESP32-CAM**           | ESP32 + 2-мегапиксельный модуль камеры + слот microSD |
| **Wemos Lolin32 Lite**  | Компактный, с разъёмом для LiPo-зарядки          |

**Языки:** Arduino C++, MicroPython, ESP-IDF — переключение через
[селектор языка](/docs/ru/programming/languages/) на панели инструментов.

## Что работает

- **WiFi**: подключайтесь к `Velxio-GUEST` и выходите в реальный интернет — см.
  [ESP32 WiFi](/docs/ru/wifi-iot/esp32-wifi/).
- **Периферия**: GPIO, PWM (LEDC), ADC, I2C, SPI, UART, а также
  таймеры/прерывания — ваша прошивка загружается с реальным журналом ROM.
- **ESP32-CAM** предоставляет доступ к камере и microSD в панелях
  компонентов симулятора.
- **Веб-прошивка**: загрузите тот же бинарный файл на физический ESP32 через USB —
  [как это сделать](/docs/ru/wifi-iot/web-flash/).

## Примечания

- Первая компиляция ESP-IDF/Arduino в сессии — самая медленная; последующие
  сборки кэшируются.
- Встроенный пример мигания светодиодом
  ([ваш первый проект](/docs/ru/getting-started/first-project/)) предназначен
  для DevKit V1.
