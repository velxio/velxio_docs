## ESP32-S3 (Xtensa LX7, двухъядерный)

| Плата                  | Особенности                                                 |
| ---------------------- | ----------------------------------------------------------- |
| **ESP32-S3 DevKit**    | Эталонная плата S3 — ускорение ИИ, много оперативной памяти |
| **XIAO ESP32-S3**      | S3 размером с большой палец от Seeed, 11 контактов          |
| **Arduino Nano ESP32** | S3 в классическом форм-факторе Nano, RGB-светодиод          |

## ESP32-C3 (RISC-V, одноядерный)

| Плата                  | Особенности                                    |
| ---------------------- | ---------------------------------------------- |
| **ESP32-C3 DevKit**    | Эталонная C3 — компактная, недорогая, WiFi+BLE |
| **XIAO ESP32-C3**      | Крошечная C3 от Seeed                          |
| **ESP32-C3 SuperMini** | Популярная плата C3 размером с почтовую марку  |

**Языки программирования** для обоих семейств: Arduino C++, MicroPython, ESP-IDF.

## Одна платформа, разные кристаллы

Всё из [страницы классического ESP32](/docs/ru/boards/esp32/) применимо и здесь —
WiFi через `Velxio-GUEST`, набор периферии, веб-прошивка — но прошивка
собирается и выполняется на соответствующем ядре: Xtensa LX7 для S3,
RISC-V для C3. Различия на уровне инструкций точно
эмулируются, поэтому бинарный файл S3 и бинарный файл C3 одного и того же скетча
ведут себя точно так же, как их аппаратные аналоги.

Ищете **ESP32-C6**, **XIAO ESP32S3 Sense** (камера + микрофон +
microSD) или **XIAO ESP32C6**? Это
[платы Pro](/docs/ru/boards/pro-boards/).
