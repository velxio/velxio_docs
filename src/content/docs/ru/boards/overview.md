Velxio симулирует платы из шести семейств. Некоторые полностью работают в вашем
браузере; более крупные работают на облачных эмуляторах Velxio — вам не нужно
делать ничего по-другому, всё просто работает, когда вы нажимаете **Play** (Воспроизвести).

| Семейство             | Платы                                                       | Языки                               |
| --------------------- | ----------------------------------------------------------- | ----------------------------------- |
| Arduino / AVR         | UNO, Nano, Mega, ATtiny85                                   | Arduino C++                         |
| ESP32 classic         | ESP32 DevKit, DevKit-C v4, ESP32-CAM, Lolin32 Lite          | Arduino C++, MicroPython, ESP-IDF   |
| ESP32-S3              | ESP32-S3, XIAO ESP32-S3, Arduino Nano ESP32                 | Arduino C++, MicroPython, ESP-IDF   |
| ESP32-C3              | ESP32-C3, XIAO ESP32-C3, C3 SuperMini                       | Arduino C++, MicroPython, ESP-IDF   |
| RP2040 / RP2350       | Raspberry Pi Pico, Pico W, Badger 2350 (Pro)                | Arduino C++, MicroPython            |
| STM32                 | Blue Pill, Black Pill, F4 Discovery, Olimex H405, Netduino  | Arduino C++                         |
| Raspberry Pi (Linux)  | Zero, 1, 2, 3, 4, 5                                         | Python в полном Linux-терминале     |

Платы, отмеченные **Pro** (например, M5Stack Cardputer или Badger 2350),
доступны на платных тарифах — см. [тарифы](/docs/ru/getting-started/plans/).

Каждая плата имеет свою страницу в этом разделе с распиновкой, поддерживаемыми
языками и особенностями.
