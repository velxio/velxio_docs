Семейство Linux Raspberry Pi загружает **полноценную Raspberry Pi OS** в
облаке и предоставляет вам терминал — это не симуляторы микроконтроллеров, а
полноценные компьютеры.

| Плата                         | Профиль CPU         |
| ----------------------------- | ------------------- |
| **Raspberry Pi Zero / 1 / 2** | класс ARM Cortex-A7 |
| **Raspberry Pi 3**            | Cortex-A53          |
| **Raspberry Pi 4**            | Cortex-A72          |
| **Raspberry Pi 5**            | Cortex-A76          |

Все платы Pi — **Pro** — см. [тарифы](/docs/ru/getting-started/plans/).

## Как это работает

1. Разместите Pi, нажмите **Start** (Запуск) — консоль WebSocket подключается примерно
   за секунду, затем загружается Linux (ожидайте 30–60 секунд до появления оболочки; оверлей «Booting…»
   отслеживает процесс).
2. Вы попадаете в настоящую оболочку: `python3`, `pip`, `ls /sys/class/gpio` — это
   подлинное пользовательское окружение.
3. **GPIO подключен к холсту**: управляйте светодиодом через `gpiozero`, считывайте
   кнопку, общайтесь по I2C/SPI с размещенными компонентами — программные прослойки
   связывают Linux GPIO с моделируемой схемой.
4. **Панель виртуальной файловой системы** загружает ваши скрипты и файлы
   в работающий Pi.

```python
from gpiozero import LED
from time import sleep

led = LED(17)
while True:
    led.toggle()
    sleep(0.5)
```

## UNIHIKER M10

Образовательный одноплатный компьютер от DFRobot (плата на Linux со встроенным сенсорным экраном) работает
на той же инфраструктуре и также является платой **Pro** — найдите её в
выборе компонентов рядом с семейством Pi.
