Встроенный [режим агента](/docs/ru/ai/agent-mode/) Velxio запускает ассистента
_внутри_ приложения. **Connect AI agent** делает противоположное: он позволяет
вашему собственному агенту — **Claude Code** или **OpenAI Codex** в вашем
терминале — получить доступ к сохранённому проекту Velxio и собрать его за вас.
Схема и код появятся на вашем холсте в течение нескольких секунд, точно так же,
как если бы это сделал встроенный агент.

Это работает через [MCP](https://modelcontextprotocol.io) (Model Context
Protocol): Velxio предоставляет свои инструменты для работы со схемами и кодом
в качестве MCP-сервера, а вы подключаете к нему своего агента с помощью
персонального токена проекта.

![Модальное окно Connect AI agent с вкладками Claude Code / Codex, командой настройки и активным подключением](../../../../assets/docs/ai/connect-agent.png)

:::note
Подключение внешнего агента — функция **Pro**. Пользователи бесплатного и
Maker-планов используют встроенные режимы [Agent](/docs/ru/ai/agent-mode/) и
[Tutor](/docs/ru/ai/tutor-mode/). См. [тарифы](/docs/ru/getting-started/plans/).
:::

## Самый быстрый способ: плагин Claude Code

Если вы используете Claude Code, установите плагин — он добавит инструменты,
команду `/velxio:build` и знания о подключении за один шаг:

```
/plugin marketplace add velxio/velxio-plugin
/plugin install velxio@velxio
```

Затем сгенерируйте токен (шаги ниже), экспортируйте его и перезапустите Claude Code:

```bash
export VELXIO_MCP_TOKEN="vlxmcp_...ваш токен..."
```

Теперь команда `/velxio:build an HC-SR04 that prints distance over serial`
выполнит всю работу. `/velxio:check` проверяет и компилирует то, что уже есть.

## Подключение вручную, в три шага

1.  **Сначала сохраните проект.** Агент подключается к сохранённому проекту,
    поэтому дайте ему имя и сохраните его, если вы ещё этого не сделали.
2.  **Откройте коннектор.** В редакторе перейдите в **File → Connect AI agent
    (Claude/Codex)**, выберите вкладку **Claude Code** или **Codex CLI** и
    нажмите **Generate connection token**.
3.  **Выполните показанную однострочную настройку** в своём терминале:

    **Claude Code**

    ```bash
    claude mcp add --transport http velxio https://velxio.dev/api/pro/mcp \
      --header "Authorization: Bearer vlxmcp_your_token_here"
    ```

    **Codex** — добавьте в `~/.codex/config.toml`:

    ```toml
    [mcp_servers.velxio]
    url = "https://velxio.dev/api/pro/mcp"
    http_headers = { "Authorization" = "Bearer vlxmcp_your_token_here" }
    ```

Вот и всё. Запустите `claude` (или `codex`) и попросите его что-нибудь собрать:

> _"Using the velxio tools, wire an HC-SR04 to the board and write the
> firmware that prints the distance over serial."_

Строка состояния в модальном окне переключится на **Connected** в тот момент,
когда ваш агент совершит первый вызов, а компоненты, провода и код появятся на
вашем холсте в реальном времени.

## Что умеет агент

Ваш агент получает тот же набор инструментов, что и встроенный агент: он может
читать проект, добавлять и подключать компоненты, добавлять платы, размещать
детали на макетной плате, писать и редактировать скетч, а также проверять схему.
У него также есть **навыки** Velxio для каждого компонента — точные имена
контактов, рецепты подключения и особенности симулятора, — поэтому он правильно
подключит SSD1306 или DHT22, а не будет гадать.

Он также может **компилировать**: `compile_sketch` собирает прошивку на сервере
Velxio и передаёт агенту вывод компилятора, чтобы он мог исправить свои
собственные ошибки, а не сообщать вам код, который не собирается. Запуск
симуляции и чтение последовательного монитора по-прежнему требуют живого
эмулятора в вашей вкладке — когда сборка завершится успешно, нажмите **Run**
в Velxio.

## Вход без токена

Клиенты, поддерживающие OAuth (включая Claude Code), могут подключиться с помощью
вашей учётной записи Velxio вместо вставленного токена: укажите им
`https://velxio.dev/api/pro/mcp` без учётных данных, и они обнаружат процесс
входа, откроют браузер и попросят вас подтвердить. На экране согласия указаны
клиент и учётная запись, а полученный токен доступа привязан только к MCP-эндпоинту
Velxio.

Токены остаются самым простым путём, и в них ничего не меняется.

## Безопасность

Токен подключения — это **узкая возможность для одного проекта**, предназначенная
для вставки в сторонний CLI:

-   **Ограничен одним проектом.** Токен всегда работает только с тем проектом,
    для которого он был создан, — никогда с другими вашими проектами или учётной
    записью.
-   **Хранится в виде хэша, показывается один раз.** Velxio хранит только хэш
    токена; открытый текст показывается один раз при его генерации.
-   **Можно отозвать.** В модальном окне перечислены все активные подключения
    с кнопкой **Revoke**, а действие **Revoke all** отключает их все сразу.
    Отзыв вступает в силу немедленно.
-   **Истекает.** Каждый токен перестаёт работать через 90 дней; сгенерируйте
    новый, чтобы продолжить.

Если вы когда-нибудь вставите токен не туда, куда нужно, откройте модальное окно
и нажмите **Revoke** — старый токен перестанет действовать мгновенно.

## Примечания и ограничения

-   Изменения агента сохраняются в ваш проект, как и любые другие изменения,
    поэтому обычная история отмены и автосохранение продолжают действовать.
-   Если проект связан с [GitHub Sync](/docs/ru/getting-started/github-sync/),
    изменения агента также зеркалируются в ваш репозиторий (пакетами, чтобы
    серия изменений не создавала множество коммитов).
-   Компиляция, запуск и чтение последовательного монитора происходят в браузере,
    поэтому держите вкладку Velxio открытой, пока управляете проектом из своего
    агента.
