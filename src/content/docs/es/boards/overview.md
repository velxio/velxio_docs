Velxio simula placas de ocho familias. Algunas se ejecutan por completo en tu
navegador; las más grandes se ejecutan en los emuladores en la nube de Velxio — no tienes que hacer
nada diferente, simplemente funciona cuando pulsas Play.

| Familia              | Placas                                                                                                                                                                                              | Lenguajes                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Arduino / AVR        | UNO, Nano, Mega, ATtiny85                                                                                                                                                                           | Arduino C++                                                   |
| ESP32 classic        | ESP32 DevKit, DevKit-C v4, ESP32-CAM, Lolin32 Lite                                                                                                                                                  | Arduino C++, MicroPython, ESP-IDF                             |
| ESP32-S3             | ESP32-S3, XIAO ESP32-S3, Arduino Nano ESP32                                                                                                                                                         | Arduino C++, MicroPython, ESP-IDF                             |
| ESP32-C3             | ESP32-C3, XIAO ESP32-C3, C3 SuperMini                                                                                                                                                               | Arduino C++, MicroPython, ESP-IDF                             |
| RP2040 / RP2350      | Raspberry Pi Pico, Pico W, Badger 2350 (Pro)                                                                                                                                                        | Arduino C++, MicroPython                                      |
| Seeed XIAO           | ESP32S3 Sense, ESP32C6, RP2040, RP2350, nRF52840 Sense, SAMD21, RA4M1, MG24 Sense, nRF54L15 Sense, las placas IPS Display                                                                           | Arduino C++ (MicroPython en las de ESP32 y RP2040/RP2350)     |
| BBC micro:bit        | micro:bit V2, sola o montada en siete placas DFRobot: Maqueen Lite y Lite V5, micro:Driver, micro:IO-BOX, IO Extender, micro:Mate, Robotics & Power IO Extender ([página](/docs/es/boards/microbit/)) | MicroPython                                                   |
| STM32                | Blue Pill, Black Pill, F4 Discovery, Olimex H405, Netduino                                                                                                                                          | Arduino C++                                                   |
| Raspberry Pi (Linux) | Zero, 1, 2, 3, 4, 5                                                                                                                                                                                 | Python en una terminal Linux completa                         |

Las familias **STM32** y **Raspberry Pi (Linux)** se ejecutan en los
servidores de emulación de Velxio y requieren un plan de pago; llevan una insignia PRO en el
selector de componentes. Todas las demás placas, incluidas las de marca como la
M5Stack Cardputer y la Badger 2350, se ejecutan en el plan gratuito — consulta
[planes](/docs/es/getting-started/plans/).

Cada placa tiene su propia página en esta sección con su pinout, lenguajes
compatibles y particularidades.
