Velxio incluye una galería de **más de 400 proyectos de ejemplo** — cada uno se abre en el editor con un solo clic, listo para ejecutarse. Es el mejor punto de partida cuando estás explorando una placa o componente nuevo.

Encuéntrala en [velxio.dev/examples](https://velxio.dev/examples), o a través de **Examples** (Ejemplos) en la navegación del sitio.

![La galería de ejemplos](../../../../assets/docs/getting-started/examples-gallery.png)

## Cómo encontrar un ejemplo

- **Search** (Buscar) — prueba con una pieza o un tema: `esp32 oled`, `blink`, `dht`…
- **Board filter** (Filtro de placa) — solo ejemplos para la placa que te interesa.
- **Difficulty** (Dificultad) — Principiante / Intermedio / Avanzado.
- **Category** (Categoría) — Circuitos, Pantallas, Motores y más.

Cada tarjeta muestra una vista previa del circuito, la placa objetivo y una breve descripción de lo que demuestra el proyecto.

## Cómo usar un ejemplo

Haz clic en una tarjeta y el proyecto completo se abre en el editor — circuito cableado, código escrito, librerías declaradas. Pulsa **Run** (Ejecutar) y funciona. A partir de ahí, trátalo como tuyo: edita el código, añade piezas y [guárdalo](/docs/es/getting-started/projects/) en tu cuenta.

Los ejemplos también están enlazados desde las páginas de referencia: cada [página de pieza](/docs/es/parts/overview/) y [página de placa](/docs/es/boards/overview/) apunta a ejemplos que la utilizan, y el [inspector de piezas](/docs/es/circuit-editor/part-inspector/) dentro del editor lista proyectos de ejemplo para la pieza sobre la que hiciste clic derecho.
