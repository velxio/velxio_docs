## Guardar un proyecto

Haz clic en el **icono de guardar** (Save) sobre el árbol de archivos o presiona **Ctrl+S**:

![El diálogo de guardar proyecto](../../../../assets/docs/getting-started/save-project.png)

Asigna un nombre y, opcionalmente, una descripción. El ajuste de **visibilidad**
controla quién puede verlo:

- **Public** — cualquier persona con el enlace puede ver el proyecto.
- **Private** — solo tú. Los proyectos privados son una función del plan de pago; consulta
  [planes](/docs/es/getting-started/plans/).

Los proyectos guardados residen en tu cuenta y se abren desde cualquier dispositivo una vez que
inicies sesión.

## Iniciar un nuevo proyecto

El icono de **nuevo espacio de trabajo** (New Workspace) sobre el árbol de archivos abre el selector de plantillas:

![El selector de plantillas iniciales](../../../../assets/docs/getting-started/starter-templates.png)

Elige un **proyecto en blanco** para comenzar desde un lienzo vacío, o selecciona una placa para
obtener esa placa precolocada con un ejemplo de parpadeo listo para ejecutar, organizado por
familia (Arduino, ESP32, etc.).

:::caution
Iniciar un nuevo espacio de trabajo **reemplaza todo en el actual** — guarda
primero si deseas conservar lo que tienes.
:::

## Abrir un archivo de proyecto

El **icono de abrir** (Open) sobre el árbol de archivos carga un proyecto desde el disco:

- **`.vlx`** — el formato de proyecto propio de Velxio (circuito + código + librerías).
- **`.zip` (Wokwi)** — Velxio importa archivos de proyecto de Wokwi, para que puedas
  traer contigo proyectos existentes de Wokwi.

## Compartir un proyecto

Guarda el proyecto como **Public** y comparte su URL. Cualquier persona que abra el
enlace verá el circuito y el código, y podrá ejecutarlo por sí misma.
