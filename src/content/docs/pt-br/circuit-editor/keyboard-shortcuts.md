## Projeto

| Atalho     | Ação                             |
| ---------- | -------------------------------- |
| **Ctrl+S** | Salvar projeto                   |
| **Ctrl+B** | Compilar o código da placa ativa |

## Tela

| Atalho                     | Ação                                                           |
| -------------------------- | -------------------------------------------------------------- |
| **Delete** / **Backspace** | Remover a peça ou o fio selecionado                            |
| **Escape**                 | Cancelar o fio que está sendo desenhado                        |
| Clique direito em uma peça | Abrir o [inspetor](/docs/pt-br/circuit-editor/part-inspector/) |

## Cores dos fios

Com um fio em andamento ou selecionado — consulte
[Fiação](/docs/pt-br/circuit-editor/wiring/) para a paleta:

| Atalho  | Cor                                                                            |
| ------- | ------------------------------------------------------------------------------ |
| **0–9** | Preto, Marrom, Vermelho, Laranja, Dourado, Verde, Azul, Violeta, Cinza, Branco |
| **c**   | Ciano                                                                          |
| **l**   | Verde-limão                                                                    |
| **m**   | Magenta                                                                        |
| **p**   | Roxo                                                                           |
| **y**   | Amarelo                                                                        |

## Editor de código

Os atalhos de edição padrão que você espera (selecionar, duplicar,
alternar comentário) funcionam dentro do editor de código.

## Chat de IA

| Atalho          | Ação              |
| --------------- | ----------------- |
| **Enter**       | Enviar a mensagem |
| **Shift+Enter** | Nova linha        |
