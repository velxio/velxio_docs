O modo **Basic** é um chat com seu projeto como contexto: o assistente vê
o circuito no canvas e o código no editor, então você pode fazer
perguntas da mesma forma que faria a um colega na bancada ao lado:

![O painel de IA no modo Basic](../../../../assets/docs/ai/mode-basic.png)

Boas perguntas no modo Basic:

- _"Por que meu LED não está piscando?"_
- _"O que este erro de compilação significa?"_ (cole-o, ou apenas pergunte — ele consegue
  ler a saída)
- _"Qual pino devo usar para I2C nesta placa?"_
- _"Explique o que este sketch faz linha por linha."_

## Mecânica

- **Enter** envia, **Shift+Enter** cria uma nova linha.
- **Anexe uma imagem** com o clipe de papel (PNG/JPEG/WebP/GIF até 4 MB) —
  uma foto de uma breadboard real, um esquemático, uma captura de tela.
- **Sessões**: inicie uma nova conversa com **+**, revise as antigas
  pelo botão de histórico.
- O contador na parte inferior mostra sua cota de **cycles** para o dia e
  o mês — veja [planos](/docs/pt-br/getting-started/plans/).

O modo Basic apenas conversa. Quando quiser que o assistente _faça_ coisas no
canvas, mude para o [modo Agent](/docs/pt-br/ai/agent-mode/).
