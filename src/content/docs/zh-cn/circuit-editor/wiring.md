## 建立连接

点击任意部件上的**引脚**——一条导线会跟随您的光标开始延伸。点击目标引脚即可完成连接。导线会以正交方式（直角转弯）布线，这是原理图和面包板照片的最佳呈现方式。

- 按 **Escape** 取消已开始的导线。
- 点击导线可将其选中；按 **Delete** 可将其删除。
- 您也可以从[部件检查器](/docs/zh-cn/circuit-editor/part-inspector/)开始接线：右键点击部件并“点击引脚进行接线”。

## 导线颜色

在导线绘制过程中（或选中导线后），按相应按键即可设置其颜色——与 Wokwi 用户熟知的调色板约定相同：

| 按键 | 颜色 | 按键                        | 颜色                                 |
| ---- | ---- | --------------------------- | ------------------------------------ |
| `0`  | 黑色 | `6`                         | 蓝色                                 |
| `1`  | 棕色 | `7`                         | 紫色                                 |
| `2`  | 红色 | `8`                         | 灰色                                 |
| `3`  | 橙色 | `9`                         | 白色                                 |
| `4`  | 金色 | `c` / `l` / `m` / `p` / `y` | 青色 / 青柠色 / 品红色 / 紫色 / 黄色 |
| `5`  | 绿色 |                             |                                      |

新导线会自动采用跳线套件配色：相邻导线会选取视觉上明显不同的颜色，红色和黑色保留给电源轨。

## 面包板

当部件的引脚位于面包板孔中时，已就位的引脚上会出现**绿点**——无需悬停即可一目了然地看到“已插入并连接”。面包板的内部导轨（行和电源条）的导电方式与真实面包板完全一致。

## 电气真实性

导线不仅仅是图形：模拟引擎会求解您实际连接的电路。缺少串联电阻、短路、悬空输入——所有这些都会像在实验台上一样正常（或异常）工作。如果在电气模式下某个连接会导致部件烧毁，电路验证器会在 **Run**（运行）之前发出警告。
