## 项目

| 快捷键          | 操作                         |
| --------------- | ---------------------------- |
| **Ctrl+S**      | 保存项目                     |
| **Ctrl+B**      | 编译当前开发板的代码         |

## 画布

| 快捷键                        | 操作                                       |
| ----------------------------- | ------------------------------------------ |
| **Delete** / **Backspace**    | 删除选中的元件或导线                       |
| **Escape**                    | 取消正在绘制的导线                         |
| 右键点击元件                  | 打开其 [检查器](/docs/zh-cn/circuit-editor/part-inspector/) |

## 导线颜色

在绘制或选中导线时 — 请参阅
[接线](/docs/zh-cn/circuit-editor/wiring/) 了解颜色表：

| 快捷键   | 颜色                                                             |
| -------- | ----------------------------------------------------------------- |
| **0–9**  | 黑色、棕色、红色、橙色、金色、绿色、蓝色、紫色、灰色、白色       |
| **c**    | 青色                                                              |
| **l**    | 青柠绿                                                            |
| **m**    | 品红                                                              |
| **p**    | 紫色                                                              |
| **y**    | 黄色                                                              |

## 代码编辑器

您熟悉的标准编辑快捷键（选择、复制、注释切换）在代码编辑器中均可用。
