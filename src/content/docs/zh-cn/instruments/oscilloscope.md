通过工具栏中的 **Scope**（示波器）按钮切换示波器。它将作为底部面板在串口监视器旁边打开。

## 添加通道

点击 **+ Add Channel**（添加通道）并选择要监视的板卡引脚：

![添加示波器通道](../../../../assets/docs/instruments/oscilloscope-add-channel.png)

每个通道都有颜色和标签（板卡 + 引脚）。点击标签下方的小 **x** 可移除通道。

## 读取波形

此处示波器监视 **GPIO2** — [第一个项目](/docs/zh-cn/getting-started/first-project/)中闪烁的 LED 引脚：

![示波器上的方波](../../../../assets/docs/instruments/oscilloscope.png)

## 控制项

| 控制项             | 功能                                                                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **Time/div**       | 水平缩放，从每格 0.1 ms 到 500 ms。根据信号调整：1 s 闪烁在 100 ms/格左右读取效果最佳；1 kHz PWM 在 0.5 ms/格左右最佳。      |
| **Trigger**        | **Auto**（自由运行）、**Normal**（仅在触发时绘制）或 **Single**（单次捕获）。选择触发通道和边沿 — 上升沿、下降沿或任意边沿。 |
| **Pause / Resume** | 冻结显示以检查波形。                                                                                                         |
| **Clear**          | 清除波形。                                                                                                                   |

## 尝试内容

- **测量 PWM 占空比**：运行 `analogWrite()` 程序，在 0.5 ms/格下观察引脚，比较高电平和低电平时间。
- **捕获单次事件**：将触发设置为 **Single**（单次）、上升沿，然后按下电路中的按钮。
- **比较两个信号**：添加两个通道 — 例如编码器的 A 和 B 输出 — 并观察它们的相位关系。
