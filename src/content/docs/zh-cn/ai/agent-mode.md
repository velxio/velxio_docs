**Agent** 模式为助手赋予了“双手”。提出电路需求，它便会
在您的画布上添加元件、连接线路、编写代码、编译并运行——
全程尽在您的眼前：

![Agent 模式下的 AI 面板](../../../../assets/docs/ai/mode-agent.png)

试试这样的提示词：

- _"用 3 个 LED 搭建一个交通灯。"_
- _"为这块板子添加一个 OLED 显示屏，并在上面显示计数器。"_
- _"我的按钮读取存在抖动——请修复代码。"_
- _"将此项目转换为 MicroPython。"_

## 您始终掌控全局

每一步操作都会落入您的正常项目中：元件出现在画布上，
代码编辑器中显示修改，撤销历史也归您所有。您可以检查
它的操作、进行调整，或要求它进行下一步。如果运行失败，
Agent 会像您一样读取编译器输出和串行监视器，并不断迭代。

## 与 Agent 高效协作

- **小步优于长篇** — “添加一个 DHT22 并打印温度”
  比一段冗长的需求描述效果更好。
- **让它完成** — Agent 的一轮操作可能包含多个动作（放置、连线、
  编码、编译、运行）；面板会实时播报进度。
- 附上您想要复现的电路图片——它可以依据照片或原理图进行工作。

Agent 轮次消耗的 **cycles** 比聊天回复更多；面板底部的配额计数器
会显示今日剩余额度。请参阅
[套餐](/docs/zh-cn/getting-started/plans/)。
