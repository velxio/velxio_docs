Velxio 可模拟六个系列的开发板。部分开发板完全在您的浏览器中运行；较大的开发板则在 Velxio 的云端模拟器上运行——您无需进行任何额外操作，只需按下 **Play**（播放）即可正常运行。

| 系列                    | 开发板                                                       | 支持的语言                                |
| ----------------------- | ------------------------------------------------------------ | ----------------------------------------- |
| Arduino / AVR           | UNO、Nano、Mega、ATtiny85                                    | Arduino C++                               |
| ESP32 经典系列          | ESP32 DevKit、DevKit-C v4、ESP32-CAM、Lolin32 Lite           | Arduino C++、MicroPython、ESP-IDF         |
| ESP32-S3                | ESP32-S3、XIAO ESP32-S3、Arduino Nano ESP32                  | Arduino C++、MicroPython、ESP-IDF         |
| ESP32-C3                | ESP32-C3、XIAO ESP32-C3、C3 SuperMini                        | Arduino C++、MicroPython、ESP-IDF         |
| RP2040 / RP2350         | Raspberry Pi Pico、Pico W、Badger 2350 (Pro)                 | Arduino C++、MicroPython                  |
| STM32                   | Blue Pill、Black Pill、F4 Discovery、Olimex H405、Netduino   | Arduino C++                               |
| Raspberry Pi（Linux）   | Zero、1、2、3、4、5                                          | 在完整 Linux 终端上运行 Python            |

**STM32** 和 **Raspberry Pi（Linux）** 系列在 Velxio 的模拟服务器上运行，需要付费计划；它们在组件选择器中带有 PRO 徽章。其他所有开发板，包括 M5Stack Cardputer 和 Badger 2350 等品牌开发板，均可免费使用——请参阅[计划](/docs/zh-cn/getting-started/plans/)。

每个开发板在本节中都有独立的页面，介绍其引脚定义、支持的语言和特殊注意事项。
