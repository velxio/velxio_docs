RP2040 开发板**在您的浏览器中**运行，提供忠实的双核 Cortex-M0+ 仿真。

| 开发板                    | 亮点                                    |
| ------------------------- | --------------------------------------- |
| **Raspberry Pi Pico**     | 标准 RP2040 开发板，26 个 GPIO          |
| **Raspberry Pi Pico W**   | 同款开发板，带 WiFi 模块焊盘            |

**支持语言：** MicroPython（Pico 的原生环境）和 Arduino C++（earlephilhower 内核）。

## 支持的功能

- GPIO、PWM、ADC、I2C、SPI、UART——以及 **PIO**，RP2040 标志性的可编程 I/O 模块，这是 NeoPixel 和特殊协议示例所依赖的功能。
- 通过[串行监视器](/docs/zh-cn/programming/serial-monitor/)使用 MicroPython 的 REPL。
- 通过[网页烧录](/docs/zh-cn/wifi-iot/web-flash/)将 `.uf2` 文件烧录到真实的 Pico。

## RP2350 在哪里？

**Badger 2350**（Pimoroni 的 RP2350 电子纸徽章）是一款[专业开发板](/docs/zh-cn/boards/pro-boards/)——它启动完整的 BadgeOS 出厂固件，包括电子纸显示等所有功能。
