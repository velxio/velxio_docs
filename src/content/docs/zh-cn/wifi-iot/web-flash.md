当你的项目在模拟器中运行正常后，你可以将其烧录到**真实开发板**上，无需安装任何软件：Velxio 通过USB直接从浏览器将编译好的固件烧录到开发板。

## 环境要求

- 基于 Chromium 的浏览器（Chrome 或 Edge）——烧录器使用浏览器的串口 API，Firefox 和 Safari 不支持该功能。
- 一根支持数据传输的 USB 数据线连接开发板。
- 先关闭其他占用该端口的程序（串口监视器、IDE 等）——浏览器需要独占访问权限。

## 烧录步骤

1. 从编辑器中打开 **Flash** 对话框。
2. 选择 USB 串口——对话框会自动检测可用端口，浏览器会要求你确认授权哪个端口。
3. Velxio 使用已为你的开发板编译好的固件——与模拟器正在运行的二进制文件完全相同。
4. 观察烧录进度；完成后，开发板将重启并运行你的项目。

RP2040/RP2350 开发板烧录其 `.uf2` 文件，ESP32 开发板烧录其 `.bin` 文件——对话框会根据目标设备自动选择正确的协议。

## 先模拟，后烧录

这形成了一个完整的闭环，让 Velxio 在实际工作中发挥价值：在模拟器中快速迭代（无需连接线、不损耗硬件、即时重置），当行为符合预期时，再烧录完全相同的构建产物。
