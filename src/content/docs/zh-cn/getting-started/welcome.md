Velxio 是一款在线电子模拟器。您可以将真实的开发板和元器件放置在画布上，将它们连接起来，在内置代码编辑器中编写程序，然后按下 **Play**（播放）——您的代码将编译并在模拟开发板上运行，像真实硬件一样驱动元器件。

## 您可以模拟的内容

- **开发板**：Arduino（UNO、Nano、Mega）、ESP32 系列（经典版、S3、C3 等）、Raspberry Pi Pico 和 Pico W、STM32（Blue Pill、Black Pill、Discovery…）、完整的 Linux Raspberry Pi（Zero 到 5）以及 ATtiny85。
- **元器件**：LED、显示屏（OLED、TFT、LCD、电子纸）、传感器、电机、逻辑 IC、模拟器件，以及来自 DFRobot、Seeed、M5Stack 和 Grove 的品牌模块。
- **编程语言**：Arduino C++、MicroPython 和 ESP-IDF，具体取决于开发板。
- **仪器**：串行监视器、示波器等，用于查看您的电路实际运行情况。
