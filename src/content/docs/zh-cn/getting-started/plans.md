您可以在 Velxio 上**免费**构建、仿真和分享电路——核心仿真器、开放板卡目录、示例库和公共项目均无需任何费用。

付费计划（**Maker** 和 **Pro**）解锁需要真实计算资源或面向高级用户的功能：

| 功能                                                                                 | 免费版 | 付费计划                |
| --------------------------------------------------------------------------------------- | ---- | ------------------------- |
| 电路编辑器、代码编辑器、仿真                                                          | 是  | 是                       |
| 开放板卡（Arduino、ESP32 系列、Pico、STM32、ATtiny…）                               | 是  | 是                       |
| 示例库、公共项目                                                       | 是  | 是                       |
| **Pro 板卡**（Raspberry Pi Linux 系列、M5Stack Cardputer、Badger 2350、XIAO Sense…） | 否   | 是                       |
| **AI 助手**（基础 / 代理 / 导师）                                                | 否   | 是，按计划配额提供 |
| **私有项目**                                                                    | 否   | 是                       |
| 编译优先级和更高使用限制                                                | 否   | 是                       |

需要付费计划的板卡和组件在组件选择器中会带有 **PRO 徽章**——您始终可以查看完整目录。

AI 助手按**周期**计量使用量（显示在聊天面板底部，每日和每月配额取决于您的计划）。

有关当前价格和完整对比，请参阅[定价页面](https://velxio.dev/pricing)。要订阅或管理订阅，请参阅[订阅](/docs/zh-cn/account/overview/)。
