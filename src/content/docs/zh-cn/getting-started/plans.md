Velxio 可以免费使用，而且免费版不是演示版。电路编辑器、代码编辑器、元件目录、示例库和无限数量的公共项目都不需要任何费用，也没有任何开发板对你隐藏。

付费计划针对的是两项真正需要花钱运行的功能——**AI助手**（每次提问都是一次模型调用）和**服务器端仿真**（STM32 和 Raspberry Pi 开发板作为真实的 QEMU 进程在 Velxio 的机器上运行）——以及面向工作中使用 Velxio 的用户的功能：私有项目、导出、集成和离线桌面应用。

各层级是叠加的：**Pro 包含 Maker 的所有功能，Maker 包含 Free 的所有功能。**

## AI 助手

助手有三种模式，它们的权限限制方式并不完全相同。

| 模式 | 功能 | 适用计划 |
| --- | --- | --- |
| **Basic** | 以你的项目为上下文回答问题——"为什么我的 LED 不亮？"、"这个编译器错误是什么意思？"它会读取画布和代码，但不会修改它们。 | 所有计划，包括 Free |
| **Agent** | 对项目进行操作：添加和连接元件、编写和修复代码、运行仿真来检查自己的工作。 | Maker 和 Pro |
| **Tutor** | 在你的电路上逐步教学——提出练习、检查你搭建的内容、讲解理论。 | Maker 和 Pro |

免费版中的 Basic 模式有**独立的每日 50 条消息额度**，不会消耗你的 AI 积分。因此免费账户并不局限于每天 20 次 AI 交互——它每天可以获得 50 条 Basic 聊天消息加上 20 个积分。

### AI 积分如何计算

积分（显示为聊天面板底部的计数器）用于计量 Agent 和 Tutor 模式的工作量：

- 一个普通请求消耗 **1 个积分**。
- 一个大型请求——上下文超过约 30,000 个 token 的请求，例如针对大型项目的长对话——会按比例消耗更多积分，因此一次高负载的提示可能会花费多个积分。
- 每日计数器**在 UTC 午夜重置**。未使用的积分不会结转。
- 每月上限是在每日上限之上的第二个独立限制。
- 编辑器中的内联代码补全单独计量，永远不会消耗 Agent 积分。

有关每种模式的实际功能，请参阅 [AI 助手部分](/docs/zh-cn/ai/overview/)。

## 开发板和仿真

**目录中的每块开发板在所有计划上都是可见且可编辑的**，而且其中大多数也可以在*所有*计划上*运行*。有两个系列是例外，因为它们的托管成本较高：

| 开发板系列 | 运行位置 | Free | 付费 |
| --- | --- | --- | --- |
| Arduino / AVR、RP2040 / RP2350（Pico、Badger 2350） | 你的浏览器 | 是，无时间限制 | 是 |
| ESP32 系列（经典、S3、C3、C6）、M5Stack、XIAO | Velxio 的服务器 | 是，每次运行 1 小时 | 是，无每次运行限制 |
| **STM32**（Blue Pill、Black Pill、F4 Discovery…） | Velxio 的服务器 | 否 | 是 |
| **Raspberry Pi Linux**（Zero、1、2、3、4、5、UNIHIKER） | Velxio 的服务器 | 否 | 是 |

需要付费计划的开发板正是 STM32 系列和 Raspberry Pi Linux 系列——它们在元件选择器中带有 **PRO 徽章**。像 M5Stack Cardputer、Pimoroni Badger 2350 或 XIAO 系列这样的品牌开发板**不**设付费墙，即使它们是托管目录的一部分。

有两个限制适用于所有人，包括付费用户：

- 仿真**闲置 2 小时**后会自动停止。
- Raspberry Pi 会话有**每次会话 2 小时的硬性上限**。

一些个别功能也需要付费计划：Pico W WiFi 仿真、向模拟 microSD 卡上传文件、私有 IoT 网关，以及一小部分高级元件（它们在选择器中显示 PRO 徽章）。

| | Free | Maker | Pro |
| --- | --- | --- | --- |
| 库管理器 + 编译 | 是 | 是 | 是 |

| 以 `.zip` 格式上传自己的库 | 否 | 是 | 是 |
| 高峰时段优先编译队列 | 否 | 是 | 是 |

有关配额如何计算，请参阅 [库](/docs/zh-cn/programming/libraries/)。
