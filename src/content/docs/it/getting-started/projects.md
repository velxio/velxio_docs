## Salva un progetto

Fai clic sull'**icona di salvataggio** sopra l'albero dei file oppure premi **Ctrl+S**:

![La finestra di dialogo di salvataggio del progetto](../../../../assets/docs/getting-started/save-project.png)

Dai un nome al progetto e, facoltativamente, una descrizione. L'impostazione di **visibilità** controlla chi può vederlo:

- **Public** (Pubblico) — chiunque abbia il link può visualizzare il progetto.
- **Private** (Privato) — solo tu. I progetti privati sono una funzionalità dei piani a pagamento; vedi [piani](/docs/it/getting-started/plans/).

I progetti salvati risiedono nel tuo account e si aprono da qualsiasi dispositivo dopo l'accesso.

## Avvia un nuovo progetto

L'icona **new workspace** (nuovo spazio di lavoro) sopra l'albero dei file apre il selettore di modelli:

![Il selettore di modelli iniziali](../../../../assets/docs/getting-started/starter-templates.png)

Scegli un **blank project** (progetto vuoto) per iniziare da una tela vuota, oppure scegli una scheda per averla già posizionata con un esempio di blink pronto all'uso — organizzati per famiglia (Arduino, ESP32 e così via).

:::caution
Avviare un nuovo spazio di lavoro **sostituisce tutto ciò che è presente in quello corrente** — salva prima se vuoi conservare ciò che hai.
:::

## Apri un file di progetto

L'**icona di apertura** sopra l'albero dei file carica un progetto dal disco:

- **`.vlx`** — il formato di progetto proprietario di Velxio (circuito + codice + librerie).
- **`.zip` (Wokwi)** — Velxio importa archivi di progetti Wokwi, così puoi portare con te i tuoi progetti Wokwi esistenti.

## Condividi un progetto

Salva il progetto come **Public** (Pubblico) e condividi il suo URL. Chiunque apra il link vede il circuito e il codice e può eseguirlo autonomamente.
