Velxio simula schede di otto famiglie. Alcune funzionano interamente nel tuo
browser; quelle più grandi girano sugli emulatori cloud di Velxio — non devi
fare nulla di diverso, funziona e basta quando premi Play.

| Famiglia             | Schede                                                                                                                                                                                              | Linguaggi                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Arduino / AVR        | UNO, Nano, Mega, ATtiny85                                                                                                                                                                           | Arduino C++                                                   |
| ESP32 classic        | ESP32 DevKit, DevKit-C v4, ESP32-CAM, Lolin32 Lite                                                                                                                                                  | Arduino C++, MicroPython, ESP-IDF                             |
| ESP32-S3             | ESP32-S3, XIAO ESP32-S3, Arduino Nano ESP32                                                                                                                                                         | Arduino C++, MicroPython, ESP-IDF                             |
| ESP32-C3             | ESP32-C3, XIAO ESP32-C3, C3 SuperMini                                                                                                                                                               | Arduino C++, MicroPython, ESP-IDF                             |
| RP2040 / RP2350      | Raspberry Pi Pico, Pico W, Badger 2350 (Pro)                                                                                                                                                        | Arduino C++, MicroPython                                      |
| Seeed XIAO           | ESP32S3 Sense, ESP32C6, RP2040, RP2350, nRF52840 Sense, SAMD21, RA4M1, MG24 Sense, nRF54L15 Sense, le schede con display IPS                                                                         | Arduino C++ (MicroPython sulle versioni ESP32 e RP2040/RP2350) |
| BBC micro:bit        | micro:bit V2, da sola o montata su sette schede DFRobot: Maqueen Lite e Lite V5, micro:Driver, micro:IO-BOX, IO Extender, micro:Mate, Robotics & Power IO Extender ([pagina](/docs/it/boards/microbit/)) | MicroPython                                                   |
| STM32                | Blue Pill, Black Pill, F4 Discovery, Olimex H405, Netduino                                                                                                                                          | Arduino C++                                                   |
| Raspberry Pi (Linux) | Zero, 1, 2, 3, 4, 5                                                                                                                                                                                 | Python su un terminale Linux completo                         |

Le famiglie **STM32** e **Raspberry Pi (Linux)** girano sui server di
emulazione di Velxio e richiedono un piano a pagamento; hanno un badge PRO
nel selettore dei componenti. Tutte le altre schede, comprese quelle
brandizzate come l'M5Stack Cardputer e la Badger 2350, funzionano con il
piano gratuito — vedi
[piani](/docs/it/getting-started/plans/).

Ogni scheda ha la propria pagina in questa sezione con il pinout, i
linguaggi supportati e le sue particolarità.
