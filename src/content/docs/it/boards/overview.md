Velxio simula schede di sei famiglie. Alcune funzionano interamente nel tuo
browser; quelle più grandi funzionano sugli emulatori cloud di Velxio — non
devi fare nulla di diverso, funziona semplicemente quando premi **Play** (Esegui).

| Famiglia              | Schede                                                       | Linguaggi                           |
| --------------------- | ------------------------------------------------------------ | ----------------------------------- |
| Arduino / AVR         | UNO, Nano, Mega, ATtiny85                                    | Arduino C++                         |
| ESP32 classico        | ESP32 DevKit, DevKit-C v4, ESP32-CAM, Lolin32 Lite           | Arduino C++, MicroPython, ESP-IDF   |
| ESP32-S3              | ESP32-S3, XIAO ESP32-S3, Arduino Nano ESP32                  | Arduino C++, MicroPython, ESP-IDF   |
| ESP32-C3              | ESP32-C3, XIAO ESP32-C3, C3 SuperMini                        | Arduino C++, MicroPython, ESP-IDF   |
| RP2040 / RP2350       | Raspberry Pi Pico, Pico W, Badger 2350 (Pro)                 | Arduino C++, MicroPython            |
| STM32                 | Blue Pill, Black Pill, F4 Discovery, Olimex H405, Netduino   | Arduino C++                         |
| Raspberry Pi (Linux)  | Zero, 1, 2, 3, 4, 5                                          | Python su terminale Linux completo  |

Le famiglie **STM32** e **Raspberry Pi (Linux)** funzionano sui server di
emulazione di Velxio e richiedono un piano a pagamento; hanno un badge PRO
nel selettore dei componenti. Tutte le altre schede, incluse quelle con marchio
come la M5Stack Cardputer e la Badger 2350, funzionano con il piano gratuito —
vedi [piani](/docs/it/getting-started/plans/).

Ogni scheda ha la propria pagina in questa sezione con il suo pinout, i
linguaggi supportati e le particolarità.
