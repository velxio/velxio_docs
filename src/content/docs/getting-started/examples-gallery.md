Velxio ships a gallery of **400+ example projects** — every one opens in
the editor with a single click, ready to run. It's the best starting point
when you're exploring a new board or component.

Find it at [velxio.dev/examples](https://velxio.dev/examples), or through
**Examples** in the site navigation.

![The examples gallery](../../../assets/docs/getting-started/examples-gallery.png)

## Finding an example

- **Search** — try a part or a topic: `esp32 oled`, `blink`, `dht`…
- **Board filter** — only examples for the board you care about.
- **Difficulty** — Beginner / Intermediate / Advanced.
- **Category** — Circuits, Displays, Motors, and more.

Each card shows a preview of the circuit, the target board, and a short
description of what the project demonstrates.

## Using an example

Click a card and the full project opens in the editor — circuit wired,
code written, libraries declared. Press **Run** and it works. From there,
treat it as your own: edit the code, add parts, and
[save it](/docs/getting-started/projects/) to your account.

Examples are also linked from the reference pages: every
[part page](/docs/parts/overview/) and [board page](/docs/boards/overview/)
points to examples that use it, and the
[part inspector](/docs/circuit-editor/part-inspector/) inside the editor
lists example projects for the part you right-clicked.
