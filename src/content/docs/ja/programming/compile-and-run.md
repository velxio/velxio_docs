## Run（実行）の動作

**Run**（実行）は、アクティブなボードのコードを（必要に応じて）コンパイルし、その結果をエミュレートされたボード上で起動します。「ソースコードのシミュレーション」ではありません — Velxioは実際のツールチェーン（arduino-cli / ESP-IDF / MicroPython）を使用して**実際のファームウェアバイナリ**を構築し、それを命令単位で実行します。

- **Compile**（Ctrl+B）は実行せずにビルドします — エラーを素早く確認するのに便利です。
- **Stop**（停止）はシミュレーションを停止します。**Reset**（リセット）はファームウェアを最初から再起動します。

## 出力コンソール

左下の**OUTPUT**（出力）パネルにはビルドの進行状況が表示されます：ライブラリの解決、コンパイラの呼び出し、メモリ使用量、そして最後に`Compilation successful`（コンパイル成功）が表示されます。これはArduino IDEや`idf.py build`が出力するものと同じです。

## コンパイルエラーの読み方

エラーはコンパイラが出力するそのままの形式で、ファイル名と行番号付きで表示されます：

- `'foo' was not declared in this scope` — タイプミスまたは`#include`の欠落。
- ヘッダーに対する`No such file or directory` — ライブラリがインストールされていません。**Libraries**（ライブラリ）から追加してください（[方法](/docs/ja/programming/libraries/)）。
- 巨大なスケッチでのリンカー/セクションエラー — バイナリが選択したボードのフラッシュメモリに収まりません。

修正して、もう一度**Run**（実行）を押してください。最初のビルド以降はキャッシュにより大幅に高速になります。

> **Tip:** コンパイルエラーを[AIアシスタント](/docs/ja/ai/overview/)に貼り付けてください — エラーを文脈に沿って説明するのは、Basicモードが最も得意とするところです。

## 実行中について

- ファイルツリーのボード名の横にある**ステータスドット**は、Idle（アイドル）/ Compiled（コンパイル済み）/ Running（実行中）を表示します。
- **シリアルモニタ**は自動的に接続されます — [シリアルモニタ](/docs/ja/programming/serial-monitor/)を参照してください。
- 回路とライブで対話します：ボタンを押す、ポテンショメータを回す、センサー値をコントロールパネルから変更するなどができます。
