ツールバーの**Serial**ボタンでシリアルモニターを切り替えます。シリアルモニターは下部パネルとして開き、プロジェクト内の**ボードごとに1つのタブ**が表示されます。

![実行中のシリアルモニター](../../../../assets/docs/programming/serial-monitor.png)

ファームウェアが出力するすべての内容（`Serial.println`、MicroPythonの`print`、ブートROMログ）がリアルタイムでここに表示されます。エミュレーターが実際のファームウェアを起動するため、チップ自身のブートメッセージも含まれます。

## コントロール

- **Baud rate**（ボーレート） — `Serial.begin(...)` に合わせます。通常は115200です。
- **Autoscroll**（自動スクロール） — 最新の出力に追従します。チェックを外すと過去にスクロールできます。
- **Clear**（クリア） — バッファを空にします。
- **Hardware serial**（ハードウェアシリアル） — タブがボードのUARTに接続されていることを示します。

## 入力の送信

下部の**message box**（メッセージボックス）に入力し、**Send**を押します。行末セレクター（Newline / Carriage return / 両方 / なし）は、`Serial.read()` を解析するスケッチにとって重要です。これはArduino IDEのモニターと同じ動作です。

MicroPythonボードでは、シリアルモニターは**REPL**を兼ねます。Ctrl+Cスタイルの割り込みでスクリプトを停止し、Pythonを対話的に入力できます。
