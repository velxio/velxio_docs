ツールバーの **Libraries**（ライブラリ）をクリックすると、Arduinoライブラリレジストリを検索して、アクティブなボードにライブラリを追加できます。

インストールされたライブラリは、ボードの **`libraries.json`** ファイル（ファイルツリーに表示）に記録されるため、プロジェクトと一緒に移動します。プロジェクトを開く人（将来の自分を含む）は、コンパイル時に同じバージョンが解決されます。マシンごとにライブラリフォルダを同期する必要はありません。

## ライブラリの使用

インストールしたら、通常どおり `#include` します：

```cpp
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
```

クラウドコンパイラは、ビルド前に宣言されたライブラリ（およびその依存関係）を取得します。ヘッダーで `No such file or directory` エラーが発生してビルドが失敗した場合、そのヘッダーを提供するライブラリがまだ宣言されていません — **Libraries**（ライブラリ）から追加してください。

## MicroPython

MicroPythonファームウェアには、標準のバンドルモジュール（`machine`、`network`、`time` など）が同梱されています。純粋なPythonヘルパーモジュールは、`main.py` の隣のファイルツリーに追加ファイルとして配置し、通常どおりインポートできます。

## 例は配線済み

すべてのギャラリー例は、必要なライブラリを宣言しています。例を開くと、コード＋回路＋ライブラリバージョンの実績ある組み合わせが得られるため、独自のプロジェクトの出発点として最適です。
