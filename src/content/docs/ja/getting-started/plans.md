Velxioでは、回路の作成、シミュレーション、共有を**無料**で行うことができます。コアシミュレータ、オープンボードカタログ、サンプルギャラリー、公開プロジェクトはすべて無料です。

有料プラン（**Maker** および **Pro**）では、実際の計算リソースを必要とする機能や、パワーユーザー向けの機能を利用できます。

| 機能                                                                                     | 無料 | 有料プラン              |
| --------------------------------------------------------------------------------------- | ---- | ----------------------- |
| 回路エディタ、コードエディタ、シミュレーション                                           | あり | あり                    |
| オープンボード（Arduino、ESP32ファミリー、Pico、STM32、ATtiny…）                         | あり | あり                    |
| サンプルギャラリー、公開プロジェクト                                                     | あり | あり                    |
| **Proボード**（Raspberry Pi Linuxファミリー、M5Stack Cardputer、Badger 2350、XIAO Sense…） | なし | あり                    |
| **AIアシスタント**（Basic / Agent / Tutor）                                              | なし | あり（プランごとの割り当てあり） |
| **プライベートプロジェクト**                                                             | なし | あり                    |
| コンパイル優先度とより高い使用制限                                                       | なし | あり                    |

有料プランが必要なボードとコンポーネントには、コンポーネントピッカーに**PROバッジ**が表示されます。カタログ全体はいつでも閲覧できます。

AIアシスタントの使用量は**サイクル**単位で測定されます（チャットパネルの下部に表示され、プランに応じた日次および月次の許容量があります）。

現在の料金と完全な比較については、[料金ページ](https://velxio.dev/pricing)をご覧ください。サブスクリプションの登録または管理については、[サブスクリプション](/docs/ja/account/overview/)をご覧ください。
