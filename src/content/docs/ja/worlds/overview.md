**ワールド**は、回路を物理的なシーンに配置します。ファームウェアは実機とまったく同じようにエミュレートされたボード上で動作します。駆動するモーターはロボットを動かし、設定するサーボはアームやセンサーを回転させ、ライン・距離・モーションセンサーはロボットの下や前方にあるものを読み取ります。同じコードはその後、実機のハードウェア上でも動作します。

![ワールド内で走行するRomeo ESP32-S3ライントレーサーと、隣で動作中の回路](../../../../assets/docs/worlds/romeo-running.png)

## ワールドを開く

ボードのあるプロジェクトには、キャンバスヘッダーのボードセレクターの隣に**3D**ボタンがあります。

![ボードセレクターの隣にある3Dボタン](../../../../assets/docs/worlds/3d-button.png)

初回は、3つの入り方を示す紹介画面が開きます。

![3Dワールドの紹介画面](../../../../assets/docs/worlds/intro.png)

- **ロボットから始める**: 完成したロボットプロジェクト（ボード、配線済みのモーターとセンサー、ファームウェア、ワールド）を開き、**Run**を押します。[Romeo ESP32-S3ライントレーサー](/docs/ja/worlds/example-romeo-line-follower/)と[Devastatorタンク](/docs/ja/worlds/example-devastator-tank/)を参照してください。
- **この回路用のワールドを作成**: Velxioがキャンバス上の内容から開始シーンを構築します。モーターはロボット（2輪または4輪）になり、ラインセンサーの下にはテープで引かれたコースが配置され、距離センサーの前方には障害物が置かれ、サーボだけの場合は小さなテーブル上のロボットアームになります。
- **AIプロンプトをコピー**: ボード、パーツ、配線、ファームウェアを含む概要をChatGPT、Claude、Gemini用にコピーします。これにより、AIが説明したとおりのワールドを書くことができます。[独自のワールドを作成する](/docs/ja/worlds/write-your-own/)を参照してください。

プロジェクトにワールドができると、3Dボタンでワールドとコードを切り替えられます。

## Runを押す

シミュレーションが開始されると、エディター領域にワールドが表示され、キャンバスはその隣に残ります。ロボットが走行する間、回路側でモーターが回転するのを確認できます。ループは1秒間に約125回閉じます。

1. ファームウェアがピンを設定します。各モーターの方向とPWMデューティ、各サーボのパルスです。
2. Velxioが各モーターの駆動（回路が使用するドライバー経由）と各サーボの角度を読み取り、ワールドに送信します。
3. ワールドがロボットを動かし、シーンを計測します。各ラインセンサーの下のテープ、各距離センサーの前方の最も近い障害物、IMU用のロボットの加速度と旋回速度です。
4. Velxioがそれらの読み取り値をセンサーパーツに書き込み、ファームウェアが次の`digitalRead()`、`pulseIn()`、またはI2C転送でそれらを読み取ります。

ワールドは実時間ではなく、ボードの**シミュレーションクロック**で動作します。コンピューターがシミュレーションを半分の速度で実行すると、ロボットも半分の速度で動きますが、ファームウェアの`millis()`とは引き続き一致します。

## ワールドバー

| コントロール       | 機能                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| **World / HTML**   | シーンを表示するか、その背後にある`world.html`ソースを表示します。                                       |
| **Guide**          | シーン上にワールドの簡単な説明を表示します。                                                              |
| **Copy AI prompt** | 外部AIチャット用の概要をコピーします（[独自のワールドを作成する](/docs/ja/worlds/write-your-own/)を参照）。 |
| **Reload**         | ファイルからワールドを再起動します。                                                                      |
| **Full screen**    | ワールドのみを表示します。Escを押すと戻ります。                                                           |

Velxioのシーンキットで作成したワールドは、シーン内に独自のツールバーを追加します。**Edit**、**Add**、**3D / 2D**、**Camera**（オービット、ロボット追従、真上から）、**Reset**（ロボットを開始位置に戻す）です。[シーンを構築する](/docs/ja/worlds/scene-editor/)を参照してください。

## 3Dまたは2D

3DビューにはWebGLが必要です。**2D**トップビューは同じシーンを描画し、グラフィックスカードなしで同じ物理演算を実行するため、どの学校のコンピューターでも動作し、3Dが利用できない場合のフォールバックとなります。

![2DトップビューでのDevastatorアリーナ](../../../../assets/docs/worlds/view-2d.png)

## ワールドが対応するもの

- **読み取り**: DCモーターとギアモーター（L293D、トランジスタ、MOSFET、ボードのオンボードドライバー経由、またはピンに直接接続）、およびサーボ。
- **入力**: DFRobot Gravityライントラッカー、URM09およびURM37超音波センサー、HC-SR04、MPU6050 IMU。

その他のすべてのパーツ（LED、ディスプレイ、ブザー）はキャンバス上で引き続き動作します。詳細とファームウェアのレシピ：[モーターとセンサー](/docs/ja/worlds/motors-and-sensors/)。

## ファイルであること

ワールドは1つのファイル`world.html`で、スケッチの隣のボードのファイルグループにあります。プロジェクトとともに保存、共有、エクスポートされ、ボードには決して送られません。コンパイルされず、フラッシュに書き込まれず、microSDカードにコピーされることもありません。ファイルを削除すると、プロジェクトにはワールドがなくなります。
