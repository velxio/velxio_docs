Velxioのシーンキットで作成したWorld（**Create a world for this circuit**で作成されるすべてのWorld、および[Devastatorアリーナ](/docs/ja/worlds/example-devastator-tank/)）は、マウスで編集できます。変更は`world.html`に保存されるため、プロジェクトと一緒に移動します。

![Devastatorアリーナのシーンエディター](../../../../assets/docs/worlds/editor.png)

## 編集モード

Worldのツールバーで**Edit**（鉛筆アイコン）を押します。

- **Add**でマット上に新しいオブジェクトを配置します：

  | グループ     | オブジェクト                                                                       |
  | --------- | ----------------------------------------------------------------------------- |
  | Robots    | Robot 2WD、Robot 4WD、Robot tank（Devastator）、Robot arm                      |
  | Tracks    | ループ、楕円、8の字、直線（マット上の黒テープ）                        |
  | Obstacles | ボックス、壁、シリンダー                                                           |
  | Terrain   | ランプ、橋、丘                                                            |

- オブジェクトを**クリック**して選択し、プロパティを開きます。
- **ドラッグ**してマット上で移動します。**Q**と**E**で回転、**Shift**で15度刻みで回転、**Delete**で削除します。
- **Ctrl+Z**と**Ctrl+Y**で元に戻す・やり直し。
- **Mat settings**でマットのサイズ、色、グリッドを設定します。

3Dビューでも2Dビューでも同じように動作します。もう一度Editを押すとプレイモードに戻ります。

## ロボットを回路に接続する

ロボットは与えたモーターでのみ動き、与えたセンサーのみから入力を受け取ります。ロボットを選択し、キャンバス上のパーツから選択します：

| フィールド                     | 選択するもの                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Motors: Left / Right**  | 片側につき1つまたは2つのモーター。片側の速度はそのモーターの平均駆動に従います。                                |
| **Reverse left / right**  | 「前進」が負の駆動となる側（モーターの配線や取り付けが逆になっている場合）にチェックを入れます。               |
| **Line**                  | ライントラッカー、前面に左から右へ（最大5つ、18 mm間隔）。                                           |
| **Sonar**                 | フロントバンパーの距離センサー（URM09、URM37、HC-SR04）。                                                   |
| **Sonar servo**           | ソナーを回転させるサーボ：0度は右、90度は前方、180度は左を向きます。                                           |
| **IMU**                   | シャーシ上のMPU6050。                                                                                         |

ロボットアームは4つのサーボを使用します：ベース、ショルダー、エルボー、グリッパー。

## ロボット

| プリセット | ボディ           | フル駆動速度 | 登坂高 | 類似製品                                   |
| ------ | -------------- | ---------------- | ------ | -------------------------------------- |
| 2WD    | 15 x 10.5 cm   | 0.55 m/s         | 1 cm   | 定番の2輪キットカー          |
| 4WD    | 20 x 11.5 cm   | 0.61 m/s         | 1.5 cm | 4輪スキッドステアカー            |
| Tank   | 22.5 x 22 cm   | 0.36 m/s         | 3 cm   | DFRobot Devastator、クローラー式        |

ロボットはボックス、壁、シリンダー、マットの端で停止し、登坂高以下の高さのものは乗り越えます。ランプ上では斜面を登り、斜面に合わせてピッチングし、上りでは少し遅くなります。

## シーン形式

エディターの背後では、シーンは`world.html`内のJSONブロックです：

```html
<!doctype html>
<html><body>
<script type="application/json" id="velxio-scene">
{ "version": 1, "view": "3d", "floor": { "w": 2.4, "h": 1.6, "grid": true },
  "objects": [
    { "id": "track1", "type": "track", "shape": "loop", "x": 0, "y": 0, "w": 2.1, "h": 0.9, "tape": 0.022 },
    { "id": "robot1", "type": "robot", "preset": "diff2", "x": -0.3, "y": -0.45, "rot": 0,
      "bind": { "left": ["motorL"], "right": ["motorR"], "line": ["lineL", "lineC", "lineR"] } },
    { "id": "box1", "type": "box", "x": 0.7, "y": 0.05, "w": 0.15, "d": 0.15, "h": 0.15, "color": "#c0392b" }
  ] }
</script>
<script>velxio.kit.start();</script>
</body></html>
```

- 単位はメートルと度です。マット（`floor`、`w`×`h`）は原点を中心とします：xは右方向、yは手前から奥方向、`rot`は+xから反時計回りです。
- すべてのオブジェクトには一意の`id`、位置`x`、`y`、およびオプションで`rot`、`color`、`label`があります。
- `robot`：`preset`は`diff2`、`diff4`、`tank`のいずれかです。`bind`には`left`、`right`（モーターIDのリスト）、`invertLeft`、`invertRight`、`line`（センサーID、左から右へ）、`sonar`、`sonarServo`、`imu`が含まれます。
- `track`：`shape`は`loop`、`oval`、`figure8`、`line`のいずれかで、`w`、`h`、`tape`（テープ幅、0.019〜0.025 m）があります。原点を中心とするループのテープ上でライントレーサーを開始するには、下部の直線に+x方向で配置します：`x: -0.3, y: -h/2, rot: 0`。
- `box`と`wall`：`w`、`d`、`h`。`cylinder`：`r`、`h`。
- `ramp`：`profile`は`wedge`（+x方向に上昇し、その後垂直面）、`bridge`（上り、平坦、下り）、`hill`（滑らかな隆起、どの方向からでも通過可能）のいずれかで、`w`、`d`、`h`があります。ソナーは3 cm以上の垂直面を検出し、斜面は検出しません。
- `arm`：`bind`には`base`、`shoulder`、`elbow`、`gripper`のサーボIDが含まれます。

`bind`内の回路に存在しないIDは無視されるため、シーンがプロジェクトを壊すことはありません。[Devastatorページ](/docs/ja/worlds/example-devastator-tank/)に完全なアリーナの例があります。
