Pro ボードはカタログのプレミアム層です。豊富な内蔵ペリフェラルを備えたブランドハードウェアで、**工場出荷時ファームウェア**を起動できるほど深くエミュレートされています。これらは velxio.dev のホスト型カタログの一部であり、下記の UNIHIKER M10 を除き、**無料プランで実行できます**。有料プランが必要な唯一のボードは、STM32 および Raspberry Pi Linux ファミリーです。[プラン](/docs/ja/getting-started/plans/)を参照してください。

![Velxio キャンバス上の M5 Cardputer ADV](../../../../assets/docs/boards/cardputer-adv.png)

## M5Stack

- **M5 Cardputer**（および **Cardputer ADV**）— キーボードと TFT を備えた ESP32-S3 ポケットコンピュータ。実際の M5 ランチャーファームウェアを起動します。画面上のキーボードで入力し、アプリを実行し、スピーカーを使用できます。
- **M5Stack Core** — 320x240 TFT と 3 つのボタンを備えた、定番のスタッカブル ESP32。

## Pimoroni Badger 2350

RP2350 電子ペーパーバッジです。完全な **BadgeOS 工場出荷時ファームウェア**を起動します。A/B/C/UP/DOWN ボタンでランチャーを操作し、時計、バッジ、ギャラリーアプリを開き、電子ペーパーが実際に更新される様子を確認できます。

## Seeed Studio XIAO

- **XIAO ESP32S3 Sense** — カメラモジュール、PDM マイク、microSD を備えた S3。
- **XIAO ESP32C6** — XIAO フットプリントの WiFi 6 対応 RISC-V C6。
- **XIAO RP2040** — NeoPixel を備えた RP2040 XIAO。

## Espressif ESP32-C6

**ESP32-C6 DevKit** — RISC-V WiFi-6 チップで、ESP32 ファミリーの他の製品と同じ 3 つの言語（Arduino / MicroPython / ESP-IDF）に対応しています。

## DFRobot UNIHIKER M10

内蔵タッチスクリーンを備えた Linux シングルボードコンピュータです。[Raspberry Pi ファミリー](/docs/ja/boards/raspberry-pi/)とともにドキュメント化されており、完全な Linux ワークフローを共有します。そのファミリーの他の製品と同様に、実行には有料プランが必要です。

---

Pro ボードは、[コンポーネントピッカー](/docs/ja/circuit-editor/placing-components/)に **PRO バッジ**付きで表示されます。[スターターテンプレート](/docs/ja/getting-started/projects/)には、各ボードのすぐに実行できるプロジェクトが含まれています。
