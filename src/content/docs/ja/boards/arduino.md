AVRファミリは**完全にブラウザ内で**動作します。クラウドへの往復なしで即座に起動し、サイクル精度のAVRエミュレーションを提供します。

| ボード                 | MCU                | フラッシュ  | 備考                                                  |
| --------------------- | ------------------ | ------ | ------------------------------------------------------ |
| **Arduino UNO**       | ATmega328P, 16 MHz | 32 KB  | 初心者向けの標準ボード。デジタル14ピン + アナログ6ピン |
| **Arduino Nano**      | ATmega328P, 16 MHz | 32 KB  | UNOと同じチップをブレッドボード向けのスティック型にしたもの |
| **Arduino Mega 2560** | ATmega2560, 16 MHz | 256 KB | デジタルI/O 54、UART 4基 — ピン数を多く必要とするプロジェクト向け |
| **ATtiny85**          | ATtiny85, 8 MHz    | 8 KB   | ベアの8ピンDIPチップ。そのままブレッドボードに挿せる |

**言語:** Arduino C++。

## ハードウェアと同じように動作する詳細

- `analogWrite` PWM、タイマー、割り込み（`attachInterrupt`）、EEPROM、および
  任意のボーレートでの`Serial`は、シリコン上と同じように動作します。
- ADCはアナログ回路が提供するものをそのまま読み取ります。ポテンショメータの分圧回路を配線すれば、`analogRead`がそれを追跡します。
- 定番シールド相当の部品（LCD、74HC595、サーボ、マトリックス
  キーパッド）は、サンプル付きでカタログに含まれています。
