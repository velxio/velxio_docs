## 接続を行う

任意のパーツの**ピン**をクリックすると、ワイヤがカーソルに追従して描画されます。宛先のピンをクリックすると接続が完了します。ワイヤは、回路図やブレッドボードの写真で最も見やすいように、直角に曲がる形で配線されます。

- **Escape** キーを押すと、開始したワイヤをキャンセルできます。
- ワイヤをクリックして選択します。**Delete** キーで削除できます。
- [パーツインスペクタ](/docs/ja/circuit-editor/part-inspector/)から配線を開始することもできます。パーツを右クリックして「ピンをタップして配線」を選択します。

## ワイヤの色

ワイヤの配線中（またはワイヤを選択した状態）にキーを押すと、その色を設定できます。これはWokwiユーザーにはおなじみのパレット規則です。

| キー | 色     | キー                         | 色                                       |
| --- | ------ | --------------------------- | --------------------------------------- |
| `0` | 黒     | `6`                         | 青                                      |
| `1` | 茶     | `7`                         | 紫                                      |
| `2` | 赤     | `8`                         | 灰                                      |
| `3` | オレンジ | `9`                         | 白                                      |
| `4` | 金     | `c` / `l` / `m` / `p` / `y` | シアン / ライム / マゼンタ / パープル / イエロー |
| `5` | 緑     |                             |                                         |

新しいワイヤには、ジャンパーキット方式の自動配色が適用されます。隣接するワイヤは視覚的に異なる色が選ばれ、赤と黒は電源レール用に予約されています。

## ブレッドボード

パーツのピンがブレッドボードの穴に挿さると、挿入されたピンに**緑色のドット**が表示されます。「差し込まれて接続されている」ことが、ホバーしなくても一目でわかります。ブレッドボードの内部レール（行と電源ストリップ）は、実際のものとまったく同じように導通します。

## 電気的な現実性

ワイヤは単なる図面ではありません。アナログエンジンが、実際に配線した回路を解析します。直列抵抗の欠落、ショート、フローティング入力など、すべてが実験台の上と同じように動作（または誤動作）します。電気モードで接続がパーツを焼損させる可能性がある場合、回路検証機能が**Run**の実行前に警告します。
