## プロジェクト

| ショートカット | アクション                          |
| -------------- | ----------------------------------- |
| **Ctrl+S**     | プロジェクトを保存                    |
| **Ctrl+B**     | アクティブなボードのコードをコンパイル |

## キャンバス

| ショートカット                | アクション                                                     |
| ----------------------------- | -------------------------------------------------------------- |
| **Delete** / **Backspace**    | 選択したパーツまたは配線を削除                                   |
| **Escape**                    | 描画中の配線をキャンセル                                        |
| パーツを右クリック            | [インスペクタ](/docs/ja/circuit-editor/part-inspector/)を開く      |

## 配線の色

配線の作成中または選択中に使用可能です。パレットについては
[配線](/docs/ja/circuit-editor/wiring/)を参照してください:

| ショートカット | 色                                                               |
| -------------- | ----------------------------------------------------------------- |
| **0–9**        | 黒、茶、赤、オレンジ、金、緑、青、紫、灰、白                       |
| **c**          | シアン                                                            |
| **l**          | ライムグリーン                                                    |
| **m**          | マゼンタ                                                          |
| **p**          | パープル                                                          |
| **y**          | イエロー                                                          |

## コードエディタ

標準的な編集ショートカット（選択、複製、コメントの切り替えなど）は
コードエディタ内で動作します。

## AIチャット

| ショートカット  | アクション           |
| --------------- | -------------------- |
| **Enter**       | メッセージを送信      |
| **Shift+Enter** | 新しい行を挿入        |
