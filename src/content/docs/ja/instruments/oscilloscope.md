ツールバーの**Scope**（スコープ）ボタンでオシロスコープを切り替えます。シリアルモニタの隣にボトムパネルとして開きます。

## チャンネルの追加

**+ Add Channel**（チャンネル追加）をクリックし、監視するボードのピンを選択します:

![オシロスコープチャンネルの追加](../../../../assets/docs/instruments/oscilloscope-add-channel.png)

各チャンネルには色とラベル（ボード＋ピン）が付きます。ラベルの下にある小さな**x**で削除できます。

## トレースの読み方

ここではスコープが**GPIO2** — [最初のプロジェクト](/docs/ja/getting-started/first-project/)のLED点滅ピン — を監視しています:

![オシロスコープ上の方形波](../../../../assets/docs/instruments/oscilloscope.png)

## コントロール

| コントロール       | 機能                                                                                                                                                                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time/div**       | 水平スケール。1目盛りあたり0.1msから500msまで。信号に合わせて調整: 1秒の点滅は約100ms/div、1kHzのPWMは約0.5ms/divで最適に表示されます。                                       |
| **Trigger**        | **Auto**（フリーラン）、**Normal**（トリガー時のみ描画）、**Single**（1回のみキャプチャ）。トリガーチャンネルとエッジ（立ち上がり、立ち下がり、またはその両方）を選択します。 |
| **Pause / Resume** | 波形を検査するために表示を一時停止します。                                                                                                                                    |
| **Clear**          | トレースを消去します。                                                                                                                                                        |

## 試してみること

- **PWMデューティサイクルの測定**: `analogWrite()` スケッチを実行し、ピンを0.5ms/divで観察して、ハイ時間とロウ時間を比較します。
- **ワンショットイベントの捕捉**: トリガーを**Single**、立ち上がりエッジに設定し、回路内のボタンを押します。
- **2つの信号の比較**: 2つのチャンネルを追加 — 例: エンコーダのA出力とB出力 — それらの位相関係を観察します。
